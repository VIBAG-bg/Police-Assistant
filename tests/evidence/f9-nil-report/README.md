# Локальное исправление F9 на базе 0.43.3

Эти снимки относятся к отдельной локальной ветке `fix/f9-report-validation`. Они не являются новым опубликованным релизом и не свидетельствуют об установке в игру.

`FULL_REGRESSION.json` — полный прогон 188 групп с SHA исходников; `NEW_TESTS.json` — две новые группы; `NATIVE32.json` — настоящие x86 кадры ImGui при моделируемой сцене; `REPRODUCTION.json` — точный дефект старой 0.43.3, включая SOS; `PRESERVATION.json` — сохранность значений; `VERIFICATION.json` — общий итог. Остальные файлы содержат синтетические замеры и проверки неизменённого CEF.

Рабочие результаты находятся также в `tests/F9_*.json`. Для `tools/verify-f9-fix.py` нужны эти рабочие файлы и соседняя нетронутая 0.43.3. Проверка в настоящей GTA не выполнялась. Полный отчёт: `docs/F9-REPORT-VALIDATION-FIX.md`.
