# Проверки релиза 0.43.4

Результаты относятся к релизной версии на основе опубликованной 0.43.3 и локально проверенного исправления `0ef276913c26842865641ee252414d777c52450a`.

- `REGRESSION.json`: полный набор 188 групп и SHA всех проверенных Lua-файлов/ресурсов.
- `NATIVE32.json`: настоящее x86 окно ImGui, 84 кадра на семи разрешениях; игровая сцена моделируется.
- `CEF_BROWSER.json`: проверки неизменённого JavaScript-адаптера.
- `PRESERVATION.json`: сохранность прежних значений, пресетов и нормативного корпуса.
- `PREVIOUS_WORKER.json`: переход подготовленным update ZIP со старой 0.43.3 на обычной и CEF-копии. Настоящая игра не записывалась.
- `VERIFICATION.json`: сверка релизного кода с проверенным F9-патчем, допустимыми изменениями номера версии и точным update ZIP.

Результаты локального этапа до повышения номера сохранены отдельно в `tests/evidence/f9-nil-report/`. Его SHA относятся к исторической версии 0.43.3, а не к релизному заголовку 0.43.4.

`tools/verify-release0434.py` запускается после сборки update ZIP и локальных тестов с параметрами `--baseline ../Police-Assistant-2026-v0.43.3-dev --fix-reference ../Police-Assistant-2026-v0.43.3-f9-fix`. Рабочие JSON лежат в `tests/`. Для повторной проверки сохранённого результата нужен именно опубликованный update ZIP: новая сборка ZIP может отличаться метаданными архива.

Интерактивная проверка в настоящей GTA и Windows 7 VM этими результатами не подтверждается.
