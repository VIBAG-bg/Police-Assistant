# Проверки 0.43.3

Снимки результатов относятся к исходникам этого выпуска. Это тестовые данные, не личные файлы установленной игры.

- `REGRESSION.json`: полный LuaJIT-прогон с SHA исходников и ресурсов.
- `CEF_BROWSER_RESULTS.json`: проверки JavaScript в изолированном окружении.
- `CEF_NATIVE32_RESULTS.json`: настоящий x86 LuaJIT/LuaSocket и HTTP, функция отправки HUD в V8; поле чата моделируется.
- `BROWSER_PERFORMANCE.json`: клавиатура, буфер обмена, мышь и кадры настоящего Chromium, тестовая страница 1152×864. Прогон 0.43.3 — 15 минут; базовые режимы — по 15 секунд. Максимумы этих разных по длительности измерений не доказывают причинность.
- `LUA_BENCHMARK.json` и `LUA_BENCHMARK0432.json`: агрегаты CPU с подменёнными игровыми API.
- `REPRODUCTION.json`: новые регрессии воспроизведены на исходной 0.43.2.
- `PRESERVATION.json`: сохранность прежних значений, пресетов и нормативного корпуса.
- `PREVIOUS_WORKER.json`: установка подготовленного update ZIP старым worker 0.43.2 на обычную и CEF-копию.
- `INSTALLER.json`: установка, повторная установка, резервные копии и 12 точек отката. Локальный путь тестовой папки удалён.
- `CEF_PROVENANCE.json`: SHA старых скачанных официальных архивов и нового адаптера.

`python tools/verify-release0433.py` сверяет эти результаты с исходниками и точным `pa26-update.zip` выпуска в корне проекта. Повторно собранный ZIP может иметь другой SHA из-за метаданных архива; для проверки сохранённого результата нужен опубликованный файл выпуска.

Для полного воспроизведения регрессий и сохранности разместите исходную 0.43.2 в соседней папке `Police-Assistant-2026-v0.43.2-dev`. Нативным проверкам нужны локальные x86 зависимости и путь к штатному HUD. Они не запускают и не изменяют GTA.

Реальный игровой input lag, поведение сервера и Windows 7 VM этими снимками не подтверждены. См. `docs/CEF-ACCEPTANCE-0.43.3.md`.
