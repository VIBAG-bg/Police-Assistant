# Проверки и границы подтверждения

Выпуск 0.39.0 включает исправление названий и коротких команд, ручные команды с RP-подтверждением, перенос встроенных действий, настройку второго кольца и обновление базы/помощника по публичным темам EPD/FBI. Загрузчик протокола 1 сохранён побайтно.

Проверки текущего дерева и результаты публикации записываются в `docs/release-validation.json`. В репозитории нет персональных снимков файлов установленной игры.

Текущие проверки выполнялись в изолированных папках и в подменённом игровом окружении. Нативный ImGui загружен без запуска GTA, без записи файлов игры и без серверных отправок. По просьбе пользователя установленная игра этой задачей не обновлялась.

Демо и локальные тесты не подтверждают доступность серверной команды, применение звёзд, актуальность правил или реальные полномочия персонажа. Актуальный контракт `/su ID раздел подпункт` основан на предоставленных серверных меню и подтверждении пользователя.

## Проверки дерева 0.39.0

- LuaJIT: **145/145 групп**, 8,388,118 проверок, 239 Lua-файлов.
- CEF-адаптер: **482** проверки, включая короткие команды с первой отправки.
- Update worker: **135** проверок.
- Настоящий x86 Lua/ImGui: **13,745** проверок в 1,273 кадрах. Четыре разрешения от 640×480, страницы маски, паспорта, телефона, OOC и новое подтверждение ручной команды; отсутствие обрезанных кнопок и прокрутки в подтверждениях.
- Установщик: обычная и CEF-установка, повторная установка и пять точек отката (1, 37, 89, 91, 92); личные документы сохранены.

## Проверка опубликованного релиза

После загрузки архивов сам worker должен прочитать настоящий GitHub Release, найти стабильную 0.39.0 и проверить все 91 программный файл в отдельной тестовой папке. Это не установка в игру. Результат публикуется после проверки; во время сборки он ещё имеет статус ожидания.

[Текущий результат проверки публикации](https://github.com/VIBAG-bg/Police-Assistant/blob/main/docs/published-release.json) · [GitHub Actions](https://github.com/VIBAG-bg/Police-Assistant/actions). Содержимое этих страниц может быть новее снимка документации внутри установочного ZIP.
