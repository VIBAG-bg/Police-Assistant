# Проверки и границы подтверждения

Локальная сборка 0.41.0 для проверки: **[Copilot, совместимость и сохранность](COPILOT-041-VERIFICATION.md)**. Опубликованная 0.40.3: [авторские наборы](PRESETS-043-VERIFICATION.md). Предыдущие проверки: [0.40.2](SETUP-042-VERIFICATION.md), [0.40.1](SETUP-041-VERIFICATION.md), [интерфейс 0.40.0](UX-040-VERIFICATION.md). Загрузчик протокола 1 сохранён побайтно.

Проверки текущего дерева и результаты публикации записываются в `docs/release-validation.json`. В репозитории нет персональных снимков файлов установленной игры.

Текущие проверки выполнялись в изолированных папках и в подменённом игровом окружении. Нативный ImGui загружен без запуска GTA, без записи файлов игры и без серверных отправок. По просьбе пользователя установленная игра этой задачей не обновлялась.

Демо и локальные тесты не подтверждают доступность серверной команды, применение звёзд, актуальность правил или реальные полномочия персонажа. Актуальный контракт `/su ID раздел подпункт` основан на предоставленных серверных меню и подтверждении пользователя.
