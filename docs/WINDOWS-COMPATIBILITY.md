# Windows 7, 10 и 11

[← Установка PA](INSTALLATION.md)

Установщик и обновлятор PA используют **Windows PowerShell 5.1** и **.NET Framework 4.5.2 или новее**. На Windows 10/11 нужные компоненты обычно уже есть. Windows 7 требуется **Service Pack 1** и отдельная подготовка.

## Если у тебя Windows 7 SP1

1. В «Панель управления → Система» проверь SP1 и разрядность Windows.
2. При отсутствии подходящего .NET установи [.NET Framework 4.8 Runtime с сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48). Уже установленная 4.5.2–4.7.2 тоже подходит.
3. Скачай [Windows Management Framework 5.1 у Microsoft](https://www.microsoft.com/en-us/download/details.aspx?id=54616). Для 64-битной Windows 7 — `Win7AndW2K8R2-KB3191566-x64.zip`, для 32-битной — `Win7-KB3191566-x86.zip`. Распакуй пакет и следуй вложенной инструкции Microsoft.
4. Перезагрузи компьютер, распакуй полный архив PA и снова запусти **«Установить PA.cmd»**.

PA не устанавливает системные компоненты Windows скрытно. Если проверки не пройдены, файлы игры не меняются. В полном архиве есть автономная HTML-инструкция, которую открывает сам помощник.

## Нужен ли администратор?

Обычно нет. Он может понадобиться, если сама GTA находится в защищённой папке и появляется именно «Отказано в доступе». Распакуй PA в обычную папку пользователя; не запускай его прямо из ZIP.

Сообщение `You must provide a value expression ... '-' operator` относится к разбору команды: старый PowerShell не понимает современный синтаксис. Повышение прав его не обновляет. Новый запускатель проверяет среду заранее и объясняет следующий шаг в отдельном окне.

Ошибка `Get-PaSetupExplanation is not recognized` в установщике до 0.41.2 связана с обработчиками окна, а не с правами администратора. Скачай полный установочный архив 0.41.2 или новее, распакуй его целиком в отдельную обычную папку и запусти «Установить PA.cmd» оттуда. Предыдущую сборку в игре удалять не нужно: установщик сохраняет личные данные. Эта ошибка воспроизведена и исправлена в Windows PowerShell 5.1; отдельный прогон в Windows 7 VM не заявляется.

## Если не проходит загрузка

Для GitHub и библиотек нужны HTTPS с TLS 1.2 и рабочие корневые сертификаты Windows. Проверь обновления Windows и .NET. PA сохраняет проверку сертификатов; небезопасный обход не используется.

Матрица требований, ранний отказ и текущие окна проверены автоматически. Отдельная проверка выпуска в настоящей Windows 7 не выполнялась. Совместимость самой GTA-сборки и сторонних ASI зависит от их компонентов.
