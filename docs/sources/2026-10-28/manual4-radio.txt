РАЗДЕЛ 1. ДОКЛАДЫ В РАЦИЮ.
110. ИНФОРМАЦИЯ О РАДИО-ДОКЛАДАХ И КОДИРОВКАХ​
Доклад - это форма подачи сообщения о действии, которые выполняет сотрудник полиции. Доклад составляется в свободной форме по шаблону в рамках разумного.​
Шаблон подачи доклада:
Сообщаете свою маркировку(при выходе на смену указываете маркировку, которую будете использовать в течении всей смены), следом описываете саму ситуацию, которая с вами происходит с подробностями, в конце код ситуации(CODE 0/1/2/3 и тд). (( Использование десятичных и прочих кодов не обязательно, главное - ясно и понятно передать суть своей ситуации в /f ))
Пример доклада о выходе на смену:
Офицер второго класса Гуерра, выхожу на смену как 1-L-1, доступен.
Офицер второго класса- ваше звание.
1-L-1 - это маркировка, она зависит от вашей полицейской станции, должности и отдела.
Пример доклада о проведении 10-55:
1-L-1, провожу остановку чёрного премьера на Рока Эскаланте, код 4
1-L-1 - ваша маркировка.
черный премьер - автомобиль.
Рока Эскаланте - район. Можно указывать любые ориентиры, чтобы в случае чего, офицеры могли прийти к вам на помощь.
Пример доклада об окончании проведения траффик-стопа:
1-L-1, заканчиваю проведение остановку чёрного премьера на Рока Эскаланте, продолжаю патрулирование.
Пример доклада о перерыве:
1-L-1, взял код 7.
Пример доклад о принятии вызова 911:
1-L-1, работаю по последнему вызову в 9-1-1 об ограблении, код 2/3.
Пример доклада по прибытию на место, выходя из автомобиля говорить код 6 не обязательно.
1-L-1, прибыл на место вызова, опрашиваю граждан, код 2/3
Это примерные доклады. Доклады делаются в свободной форме.Глпаное- передать суть сообщения.

10-1 - Встреча всех офицеров на дежурстве (включая локацию и код).
10-3 - Радиомолчание (для срочных сообщений).

10-5 - Повторите последнее сообщение.

10-7 - Ожидайте.

10-9 - В настоящее время занят/недоступен (детективы на ситуации).
10-11 - Режим ожидания.
10-14 - Запрос транспортировки (включая локацию и цель транспортировки).
10-15 - Подозреваемые арестованы (включая кол-во подозреваемых, локацию).
10-18 - Требуется поддержка дополнительных юнитов.
10-20 - Локация.
10-21 - Сообщение о статусе и местонахождении, описание ситуации.
10-22 - Направляйтесь в 'локация' (обращение к конкретному офицеру).
10-27 - Меняю маркировку патруля (включая старую и новую маркировку).
10-30 – Дорожно-транспортное происшествие.
10-40 - Большое скопление людей (4 и больше).
10-41 - Нелегальная активность.
10-46 - Провожу обыск.
10-52 - Запрос EMS.
10-55 - Траффик Стоп.
10-56 - Запрашиваю информацию (включая номер авто/имя подозреваемого).
10-57 VICTOR - Погоня за автомобилем (включая модель авто, цвет, местонахождение, направление движения и сообщение о переходе в TAC).
10-57 FOXTROT - Пешая погоня (включая внешность подозреваемого, оружие (если имеется), местонахождение, направление движения, TAC)
10-60 - Информация об автомобиле (включая название авто, цвет, количество людей внутри).
10-61 - Информация о пешем подозреваемом (включая расу, одежду).
10-66 - Остановка повышенного риска (если известно, что подозреваемый в авто вооружен/совершил преступление. Если остановка произошла после погони).
10-70 - Запрос поддержки (включая количество юнитов, код).
10-71 - Запрос медицинской поддержки.
10-99 - Ситуация урегулирована.

Спойлер: Ситуативные коды
Code 0 - Необходима немедленная поддержка. Все офицеры на дежурстве обязаны бросить все, чем занимаются в данный момент (не важно погоня это или арест) и направиться на место, где объявлен КОД 0.
Code 1 - Офицер в бедственном положении. Повышенный КОД 3, где офицеру срочно требуется помощь, однако ситуация не настолько серьезная, чтобы объявлять КОД 0.
Code 2 - Вызов с малым приоритетом (без сирен/стробоскопов).
Code 3 - Срочный вызов (сирены, стробоскопы).
Code 4 - Помощь не требуется.
Code 4 - ADAM - Помощь не требуется, при этом подозреваемый потерян. Дополнительные юниты, которые прибыли, продолжают поиски, при этом, юниты которые в пути прекращают движение к месту объявления.
Code 5 - Всем патрулям стоит держаться на расстоянии от данного места, за исключением экстренных ситуаций, требующих реагирования.
Code 5 EDWARD - В основном объявляется для (ASD) Air Support Division, для места где летающие средства департамента могут быть подвержены повреждениям, а так же химическому разрушению, либо наблюдение за данной зоной невозможно из-за сильного задымления.
Очищаю(Clearing) Code 5 - Зона объявления CODE 5 заново свободна и доступна для патрулирования, всем патрулям разрешено посещать данную местность.
Code 6 - Задерживаюсь на месте (включая локацию и причину (например, 911)).
Code 7 - Перерыв на обед. . В случае объявление CODE 0, CODE 1 реагируют вне зависимости от ситуации. Можно брать на срок до 15 минут. (искл: важные брифинги или вызовы)
CODE 100 - код радиомолчания при взаимодействии офицеров на одной из тактических волн.


Спойлер: Маркировки
Маркировка состоит из трёх частей
Часть первая - принадлежность к полицейской станции (1,2 или 3).
1 - полицейская станция Лос Сантоса.
2 - полицейская станция Сан Фиерро.
3 - полицейская станция Лас Вентурас.
Вторая и третья часть - вид патруля(LINCOLN, ADAM и тд.) и условное обозначение (числа от 1 до 100)
LINCOLN (сокращенно "L")- одиночный патруль офицера полиции.
LINCOLN-10 - Watch Commander(Начальник смены)
LINCOLN-20 - Assistant Watch Commander(Заместитель начальника смены)
LINCOLN-30/40/50/60 - начальник группы или отдела.
ADAM (сокращенно "A") - патруль с напарником.
DAVID - маркировка Platoon D (S.W.A.T.)
DAVID - 20 - маркировка командира отряда
ROBERT - маркировка Internal Affairs Division.
ROBERT-10 - начальник отдела IAD.
Например: 1-L-1.
1 - полицейская станция Лос Сантос.
L - lincoln, то есть одиночный патруль без напарника.
1 - условное обозначение вашей патрульной единицы.
