# Проверка исправления F9 в игре

Исправление включено в 0.43.4. Проверка в настоящей игре ещё открыта; выполненные инженерные и нативные x86 тесты её не заменяют. Этот список предназначен для проверки после обновления. Сбрасывать настройки не нужно.

- [ ] Открыть F9.
- [ ] Перейти в «Напарники».
- [ ] Открыть подраздел «Патруль».
- [ ] Проверить все пять предпросмотров: начало, продолжение, завершение, состав экипажа, периодический доклад.
- [ ] В своём шаблоне с `{direction}` при неизвестном курсе увидеть понятное предупреждение. F9 должен оставаться открытым.
- [ ] Вернуться в «Контакты» раздела «Напарники».
- [ ] Открыть «Настройки».
- [ ] Закрыть и снова открыть F9.
- [ ] Проверить доклад при действительно наблюдавшемся движении на север: должен подставиться север.
- [ ] Остановиться: действующий последний наблюдавшийся курс сохраняется по прежним правилам. При явно неизвестном курсе стандартная необязательная фраза убирается; личный шаблон с курсом показывает предупреждение.
- [ ] Проверить предпросмотры SOS, Shots fired и CODE 0 в подходящих условиях. Отправлять реальные тревоги исключительно ради теста не нужно.
- [ ] Убедиться, что личные шаблоны, история патруля, напарники, бинды и заметки сохранились.
- [ ] Убедиться, что открытие раздела, предупреждение и восстановление UI не отправляют команды.
- [ ] Проверить плавность открытия и работы F9, а также обычного ввода в CEF.

Если возникнет настоящее исключение отрисовки, штатное восстановление F9 / `/pa26repair` сохранено. Обычная ошибка заполнения доклада не должна требовать восстановления.
