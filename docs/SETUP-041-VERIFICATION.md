# Проверки установки и обновления 0.40.1

[← Проверки проекта](VALIDATION.md) · [Установка](INSTALLATION.md)

Проверки выполнены без запуска GTA, серверных команд и записи в установленную игру. Вместо игры используются отдельные папки с тестовыми данными. Проверка настоящей папки Exsellent Launcher выполняется только с `-VerifyOnly`.

| Проверка | Результат |
|---|---|
| Основная регрессия LuaJIT | 148 групп, 8 814 057 проверок |
| Сохранность модели PA | 1175 путей настроек и типов, базовые бинды, переменные, база знаний и неподвижный загрузчик совпадают с 0.39 |
| CEF-адаптер браузера | 482 проверки; JS-файлы не изменены |
| Помощник обновления | 148 проверок, включая обычный клиент, чужой CEF, совместимый CEF и отказ при изменённом контракте |
| Установщик | Обычный чат, CEF, повторная установка, проверка без записи, личные копии, 7 точек отката |
| Подготовка зависимостей | 124 проверки, включая настоящие официальные архивы, повреждения, дубликаты путей, обход каталогов, ссылки и сетевой сбой |
| Докачка и установка | 3 официальных архива, 21 проверенный файл; новая и повторная установка на макет обычной сборки |
| Настоящие x86 библиотеки | 7 проверок новых ImGui/iconv: кадры, шрифты и CP1251/UTF-8 |
| Настоящий x86 запуск помощника | 13 проверок скрытого процесса, Unicode-пути, ответа и UI |
| Старый помощник 0.38/0.39/0.40 → 0.40.1 | Пакет принят и установлен на обычный и CEF-макет; 91 программный файл, личные данные и CEF сохранены |

Помощники обновлений установленной 0.38.0, 0.39.0 и 0.40.0 совпадают побайтно. Проверка перехода использовала именно опубликованный исходник 0.40.0, а не новый помощник вместо старого. Протокол 1 и `pa26_update_platform.lua` не менялись.

Все недостающие библиотеки готовятся до записи в игру. В полной установленной библиотеке допускаются пользовательские отличия; неполная библиотека с несовпадающими существующими Lua/DLL отклоняется. При ошибках подготовки целевая папка остаётся прежней. Работоспособность сторонних ASI и ответы сервера этими проверками не подтверждаются.

Повторить основные проверки можно командами из [руководства разработки](DEVELOPMENT.md). Для дополнительной проверки официальных архивов `tests/test_setup.ps1` принимает `-OfficialCache` с каталогом уже скачанных ZIP, названных по SHA-256. `tests/test_dependencies_native32.lua` использует `PA_DEPENDENCY_LIB` и отдельный 32-битный хост, не запускающий GTA.
