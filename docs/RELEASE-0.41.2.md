# Police Assistant 0.41.2

Исправление запуска установщика, машины с игроком за рулём и пять RP-вызовов в дополнение к 0.41.1.

- **Выбор водителя.** По умолчанию пустые автомобили, NPC и машины с одними пассажирами исключены из нового выбора. Подключённый водитель становится целью взаимодействия и `{select_id}`. Уже выбранная машина остаётся захваченной после выхода водителя; доступны возврат в салон и пешая погоня. Защита от повторно выданного ID сохраняется.
- **Одноразовый переход настроек.** На профилях до этого выпуска включаются только «Только с игроком за рулём» и «Водитель — цель биндов» (`copilot_migrated = 2`). Их можно снова выключить вручную. Все остальные настройки, личные тексты, бинды, заметки, профиль и контакты сохраняются.
- **F4 → Трафик и погоня / Патруль → Вызовы и спецситуации (RP + Рация).** 9-1-1, поиск угнанного автомобиля, ограбление бизнеса, АЗС и банка. В машине — RP с терминалом, пешком — КПК и рация; после RP идёт доклад. Чужая машина и человек не обязательны. Тексты, канал, RP и условия настраиваются с предпросмотром.
- **Ограбление бизнеса.** Перед подтверждением показывается напоминание о составе при оценке ниже двух сотрудников (порог настраивается). Радар и число пассажиров — ориентир, фактический состав проверяет офицер.
- **АЗС.** Отдельное требование грабителям через выбранный канал мегафона, с напоминанием о контексте применения. Счётчик предупреждений по колёсам при этом не увеличивается.
- **«Потерян».** При отсутствии выбранной машины используется редактируемая запасная формулировка. Старые быстрые доклады и собственные настройки остаются доступны.
- **Установщик Windows.** Исправлена ошибка `Get-PaSetupExplanation is not recognized` в обработчиках выбора папки и установки. У окна обновления исправлена та же причина потери доступа к функциям. Проверяются настоящие события окна, включая неверную папку, запуск и завершение установки.

Отправка выполняется после ДА в общем исполнителе PA; НЕТ ничего не отправляет. Изменившаяся сцена, режим, настройки или состав относительно порога требуют свежего подтверждения. PA не создаёт серверный вызов/GPS-точку и не подтверждает допустимость применения силы.

Пункты 3.1 / 10.4 и 8.2 [общего регламента EPD/FBI](https://forum.exsellentrp.com/threads/yedinyi-reglament-i-pravila-dlya-sotrudnikov-epd-i-fbi.201/) сверены отдельно 28.10.2026. Полный снимок базы знаний остаётся от 25.10.2026.

Обновление доступно через прежнюю кнопку PA. Замороженный загрузчик, CEF-адаптер, порядок установки и резервирования не изменены. Для старых установок с неисправным обновлятором используйте полный установщик с последнего релиза. Авторские наборы не переписаны. Для Windows 7 по-прежнему нужны SP1, Windows PowerShell 5.1 и .NET Framework 4.5.2+; отдельная проверка на Windows 7 в виртуальной машине не выполнялась.
