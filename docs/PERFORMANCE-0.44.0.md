# Производительность 0.44.0

Это синтетические измерения отдельных обработчиков, не задержка от физической клавиши до изображения в GTA. FPS и реальные игровые frame-time spikes здесь не измерялись. Тексты чата не записывались.

Собственные CEF JS и endpoint побайтно совпадают с поддерживаемой 0.43.5; переработка native UI не добавляет обработку черновика при наборе. Иконки/сравнение источников не загружаются по нажатию клавиши. Нормативный аудит выполняется вне игрового runtime. Загрузка шрифта однократная.

## CEF / Node + инструментированный DOM-стенд

Использованы реальные производственные обработчики, 550 строк истории и по 12 000 событий каждого из десяти видов на вариант: русский/английский набор, Backspace, выделение слова/перетаскиванием, Ctrl+A/C/V, длинный ввод и посторонние события. Это не полный браузерный layout/paint и не игровой CEF. Контроль PA_OFF, исходная 0.43.2 и кандидат 0.44.0 прогоняются одним стендом.

| Вариант | Наибольший p95 обработчика среди сценариев, мс | Обращения к черновику/DOM/IPC при редактировании |
|---|---:|---|
| PA_OFF | 0.001800 | 0 чтений/записей текста, style/rect, endpoint и IPC |
| v0.43.2 | 0.002400 | 0 чтений/записей текста, style/rect, endpoint и IPC |
| v0.44.0 | 0.001400 | 0 чтений/записей текста, style/rect, endpoint и IPC |

Отдельная регрессия CEF — 578 проверок: отправка/валидация, акцент, длинные части, RP, каналы, команды, восстановление и отсутствие дубликатов. Синтетика не доказывает, что пользователь перестанет видеть фризы; это обязательный отдельный критерий игровой приёмки.

## Граница текущего клиента

При чтении установленный `main.js` уже имел SHA, отличный от закреплённого контракта 24.10.2026. Два событийных литерала не найдены в его тексте; это не доказывает отсутствие событий во время выполнения (возможны обфускация или другая сборка). Файл не изменён, контракт не перебазирован догадкой. Повторяемый переход старым worker проверяется на сохранённом официальном снимке с точным совпадением закреплённого SHA. Свидетельство наблюдения — `qa/0.44.0/LIVE_CEF_REFERENCE0440.json`.

Для текущего игрового клиента остаются 15 минут PA ВКЛ/ВЫКЛ: русский/английский ввод, удержание Backspace, выделение мышью, Ctrl+A/C/V, длинное сообщение, /me, /do, /r, обычная речь, открытие/закрытие чата, оружие и перезапуск PA. Измерять нужно input-to-paint и frame-time на одном и том же клиенте; проверять отсутствие потерь/дубликатов, а не только время JS-функции. См. также [ручную приёмку геометрии](GEOMETRY-0.44.0.md).

Воспроизведение синтетики: `node tests/benchmark_cef0440.js <baseline-0.43.2>` и `python tools/benchmark0440.py --baseline <baseline-0.43.2>`. Сначала установить Lupa/LuaJIT зависимости тестового окружения. Нативные проверки дополнительно требуют доступного x86 mimgui; собственные DLL в комплект не копируются.


## Однократная проверка контракта

В 0.44.0 новый `pa26_cef_compat` читает и проверяет SHA-256 `main.js` один раз при старте, вне прежнего моста. Неизвестный контракт не запускает IPC и не разрешает правку HTML. 1000 повторных обращений возвращают кэш без файловых чтений. На тестовом ноутбуке единственный измеренный запуск занял 1295.254 мс (включая чтение/системный SHA). Это возможная задержка запуска, а не обработка каждого символа; её нельзя скрывать в статистике ввода.

Побайтно прежними остались `pa26_chat_bridge.lua`, `pa26-chat.js`, `pa26-chat-endpoint.js`, worker и платформа обновления. При неизвестном HUD CEF-интеграция выключена до отдельной проверки; это ограничение совместимости, не подтверждение производительности нового клиента. Новый доклад обрабатывается только после фактической отправки команды и не наблюдает редактирование текста.
