# PA 0.43.0: согласованный объём

База: опубликованная 0.42.3 (`8a957afd4237260ce2066b464685016eee488442`). После разбора `gemini-code-1793270997193.md` пользователь 29.10.2026 подтвердил: «Давай аккуратно реализовывать».

Реализуются два независимых колеса и новая вкладка ВАЖНОЕ. Пользователь отдельно уточнил: новый дашборд из десяти подробно разобранных памяток рисуется с нуля в том же разделе и окне; вся прежняя база со своим интерфейсом и возможностями сохраняется как РЕЕСТР. Видимые ссылки могут оставаться только в реестре. Точность памяток определяется предоставленными источниками, а не примерами Gemini.

При разборе отклонены неверные суммы АК, номера разделов `/su`, составы RP-команд, смешение интервала тайзера с ожиданием после предупреждения, минимум двух вместо трёх для задержания в опасном районе, неподтверждённые таймеры штурма и некорректные ограничения манёвров.

Для старых пользователей сохранено общее колесо до явного включения разделения. Новые автомобильные поля заполняются копией старого колеса; уже сохранённые значения не заменяются. Первоначальный автомобильный набор для новой установки добавлен в публичные наборы без изменения прежних полей. Чужие прямые привязки не переносятся вместе с настройками: ID принадлежат файлу биндов.

Программный обновлятор, замороженный загрузчик и CEF не меняются. Оригинальные нормативные тексты и старые пути данных сохраняются. Реальная игра не является местом автоматических тестов; проверка выполняется в отдельных папках и Lua-состояниях.
