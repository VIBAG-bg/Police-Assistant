| --- | --- | --- |
| Общая RP-политика | Подготовка плана, активная очередь, отправка /setmark; не события редактирования | Workspace/Executor; до 64 шагов, старые разрешения из JSON не используются |

| Диагностика | Существующий временный cef_chat_profile; по умолчанию OFF | Фиксированные счётчики/гистограммы; никаких текстов, ID, телефонов, координат или заметок |

Новых CEF `input`, `selectionchange`, `mousemove`, DOM-observer, HTTP polling, сканирования стилей, файловых проверок или сериализации настроек при вводе нет. Две CEF JS и pa26_chat_bridge.lua не менялись. В onWindowMessage добавлена только обработка владельца Esc в ветке клавиатуры и снятие удержания при потере фокуса.

Резервные копии/атомарное хранение, реестр целей, избранное, конфликты клавиш, модальные подтверждения, уведомления и исполнитель повторно используются. `pa26_update_platform.lua` не менялся. В PS worker разрешён только дополнительный точный путь roads.bin; переход из старого worker выполняется полным установщиком. Публичные авторские presets не пересобирались из личных данных.

Профилировочные buckets: fieldNavigation, fieldPath, fieldCoordinates, fieldCruiser, fieldCleanup, fieldProjection (проекция/рисование), fieldPinned, fieldUI. Дорожный search не вызывается в render. Обычный UI не пишет native-память и не создаёт GPS-потоков.

Неподтверждённый native backend по-прежнему не вызывается. Lua-backend читает существующий файл данных лаунчера без подключения ASI, с пределами 2 МБ / 65536 узлов / 131072 рёбер и проверкой формата. Файл входит в поставку по своему единственному PA-пути; встроенный SHA проверяется порциями либо существующим Windows SHA. Источники: встроенный → выбранный → Exsellent → Legacy, без сканирования каталогов. Это отдельная реализация алгоритма, не принятие игровой отрисовки: GTA/Esc, родной waypoint и плавность остаются в ACCEPTANCE-0.45.0.md. Патча удаления blip внутри ASI нет; круиз/огни не реализованы в production.
