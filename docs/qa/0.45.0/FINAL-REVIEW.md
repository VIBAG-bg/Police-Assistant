## Реализовано

Комплектный граф с проверкой эталонного SHA и структуры, приоритетом источников, предварительной загрузкой, кэшем, прогрессом и ограниченным поиском. В каждом архиве — ровно один граф по собственному runtime-пути. Исправлены 33 неполные конверсии среди 76 точных стандартных RP-фраз; личный текст не переписывается.

Централизованная RP перед /setmark, тосты, патруль и прежние функции проходят общий прогон. Курсор обычной Esc-карты допускает расчёт; чат/диалог/потеря фокуса — нет. Автоматические тесты не доказывают настоящую отрисовку карты.

Защищённый Lua-bootstrap, GPS, прочие модули и публичные авторские наборы сохранены относительно All-in-One RC. CEF изменён только в рамках отдельного адаптивного hotfix; см. [полный отчёт](cef-hotfix/REPORT.md). В worker изменён только список владения: добавлен точный roads.bin. Main.js и DLL лаунчера не правились.

## Открытые границы

**NOT RUN:** настоящие GTA/SA:MP: waypoint → линия на ещё открытой Esc-карте, радар, zoom/pan, удаление/перемещение, совместная работа с launcher GPS, длительная сессия, FPS и задержка ввода; отдельный standalone игровой клиент; Windows 7/10 VM.

**CONTRACT_COMPATIBLE:** текущий SHA поддержан проверенным структурным профилем и DOM. Изолированный x86 IPC/handshake проходит. Настоящие CEF/игровые проверки, задержки ввода и установка на втором ПК — NOT RUN. Полный прогон старого проверенного launcher-файла BLOCKED: исходник недоступен; путь реестра покрыт fixture-тестом.

**Переход со старого worker:** прямой новый update ZIP из 0.44.0 отклоняется безопасно. Нужен однократный переход полным установщиком с сохранением данных. Новый worker устанавливает граф обычной транзакцией; обхода старой проверки нет.

Непроверенные native CPathFind, круиз и огни не включены. Сохранение назначения PA не восстанавливает исчезнувший красный waypoint GTA.
