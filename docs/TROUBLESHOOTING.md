# Решение проблем

[← На главную](../README.md)

| Симптом | Проверить |
|---|---|
| F9 ничего не открывает | MoonLoader, mimgui, encoding; полный комплект PA; конфликт клавиш; сообщения MoonLoader о загрузке. |
| Установщик просит закрыть GTA | Полностью выйди из игры; повтори после завершения процесса. Лаунчер может оставаться открыт. |
| Не совпадает хеш исходников | Скачай целый официальный архив заново. Не смешивай файлы разных выпусков. |
| Изменился чат лаунчера | Проверка CEF-контракта намеренно останавливает установку. Нужен совместимый выпуск PA; не отключай проверку. |
| Бинд работает только в демо | Проверь условия, выбранного игрока, переменные, служебный режим и включение действия. Демоданные не подтверждают реальный контекст. |
| Игрок не выбирается в интерьере | Проверь видимость, дистанцию и доступность сущности; попробуй список рядом. Фракция офицера не является запретом. При повторении укажи интерьер, способ выбора и версию. |
| Выбор остался после выхода из интерьера | Это настраиваемое сохранение карточки. Оно не отменяет проверки доступности перед действием. |
| `/su` не требует стоять рядом | Это предусмотрено для розыска подключённого игрока по ID; соседство нужно другим действиям, где есть такая проверка. |
| Длинный текст не переносится | Включи перенос и нужный канал. Проверь максимум трёх частей, длину одного слова и действие `/todo` до 60 символов. У команды с аргументами может не быть безопасного переноса. |
| Продолжение после прерывания не отправилось | Проверь оставшийся черновик и запусти вручную. PA не должен скрыто повторять старый Enter или отменённую последовательность. |
| Изменения файла снаружи блокируют сохранение | Сохрани копию правок, выйди из GTA и заново загрузи актуальные документы. Для обмена используй импорт. |
| Повреждён JSON / комплект восстановления | Не удаляй `.bak`, `.rollback` и журнал. Сделай копию всего `police_assistant_2026*`; не подменяй свежие данные старой общей библиотекой. |
| Обновление не найдено | Проверь `VIBAG-bg/Police-Assistant`, сеть, лимит GitHub API, стабильный/предварительный канал и номер установленной версии. |
| Пакет ждёт выхода | Закрой GTA и дождись завершения. Сам PA перезагружать вместо выхода недостаточно. |
| Есть маркер незавершённого обновления | Выйди из GTA, сохрани папку обновлений и дай восстановлению закончить. Не удаляй маркер, чтобы обойти защиту. |

## Сообщить об ошибке

В [Issues](https://github.com/VIBAG-bg/Police-Assistant/issues/new/choose) укажи версию, ожидаемый результат, шаги, что произошло, и текст ошибки без личных сведений. Если нужен скриншот, сначала закрой приватные окна и скрывай никнеймы/чат третьих лиц по необходимости. Настройки, бинды, пароли и полные игровые журналы публично не требуются.

## Удаление вручную

Полностью закрой GTA и сделай копию личных данных. Удаляй только собственные файлы PA по `INSTALL_MANIFEST.json`; другие `lib` не трогай. Оригинальный HUD восстанавливай из своей проверенной копии с учётом обновлений лаунчера. Личные `police_assistant_2026*` можно оставить для будущей установки.
