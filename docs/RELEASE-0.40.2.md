# Police Assistant 0.40.2

- Отдельное окно обновления на русском: этапы по сетке, зелёный прогресс, состояние резервных копий и понятное «Готово — можно запускать GTA». Окно остаётся после выхода из игры.
- Ранний повторный запуск GTA приостанавливает запись; после закрытия игры установка продолжается. Настоящий сбой по-прежнему запускает проверяемое восстановление. Прежняя версия после отката не обозначается успешным обновлением.
- Такой же интерфейс у полного установщика: выбор GTA/MoonLoader, сведения о недостающих библиотеках, явная кнопка установки, ход копирования и итоговая проверка.
- Исправлен запуск на старой среде Windows: проверка PowerShell/.NET выполняется до чтения современного установщика. Для Windows 7 SP1 есть отдельная инструкция; CMD больше не зависит от UTF-8-консоли. Windows 7 SP1 требует Windows PowerShell 5.1 и .NET Framework 4.5.2 или новее; Windows 10/11 используют тот же комплект.
- Бинды, заметки, профиль и личная база сохраняются. Протокол 1, неподвижный загрузчик и CEF-адаптеры прежние. Полный архив докачивает только недостающие библиотеки, а кнопка в игре обновляет только PA.

**Первый переход с 0.40.1 и старее:** загрузку выполняет уже установленный прежний помощник, поэтому новое автоматическое окно появится со следующего обновления. Чтобы видеть этот первый переход, скачай полный ZIP, распакуй, сначала начни обновление кнопкой в PA, затем запусти **«Показать обновление PA.cmd»** и выбери ту же игру. Этот пункт только показывает состояние и ничего не устанавливает. На первом переходе не запускай GTA до подтверждения: запись ещё выполняет прежний помощник. Не запускай полный установщик параллельно с обновлением.

Скачивание для установки: **Police-Assistant-v0.40.2.zip**. Для кнопки обновления используется **pa26-update.zip**. Архивы Source code не являются готовым дистрибутивом.

Проверки проводятся изолированно: копии игры, сохранность данных, откат, действующие окна и дочерние процессы. Проверка в настоящей GTA и отдельной Windows 7 остаётся пользовательской приёмкой.
