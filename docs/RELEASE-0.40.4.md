# Police Assistant 0.40.4

Исправлено сжатие списка и редактора биндов, в том числе на 1152×864 при растянутом окне. Блоки получили минимальную рабочую высоту, служебные действия собраны в меню «Действия с биндами», а при недостатке места доступна прокрутка. «Сохранить сценарий» остаётся сверху редактора. Выбор человека для проверки бинда открывается отдельной кнопкой.

После загрузки авторского набора кнопка «ОК» снова получает ввод и запускает однократный перезапуск PA. Проверена загрузка 83 биндов, применение, сохранение резервной копии и повторное открытие. Профиль, заметки и остальные личные данные сохраняются.

При первой установке PA запускается в **реальном режиме**, в том числе с авторскими настройками. Переключатель перенесён в **F9 → Настройки → 1. Профиль**: «РЕАЛЬНЫЙ РЕЖИМ · ДЕМО ВЫКЛ» / «ДЕМО РЕЖИМ · без отправки». Выбор сохраняется. При обновлении уже сохранённый режим остаётся вашим; автоматическое восстановление после повреждения настроек сохраняет защитное включение демо.

Это отдельный хотфикс к 0.40.3; Copilot 0.41 в этот выпуск не входит. Программный обновлятор, CEF и авторский бинд-лист сохранены. [Проверки и причины ошибок](https://github.com/VIBAG-bg/Police-Assistant/blob/v0.40.4/docs/HOTFIX-0404-VERIFICATION.md).
