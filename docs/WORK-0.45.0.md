# PA 0.45.0 — локальная реализация

Разрешена реализация по двум ТЗ и последнему обязательному уточнению `/setmark`. Установка в GTA, публикация и операции записи GitHub не разрешены. База — опубликованный HEAD 0.44.0 `ccabd376d4e899cd4fcbe12250c21b2656dea9d9`; все 697 файлов скопированы без изменения, контрольные суммы в `qa/0.45.0/BASELINE.json`. Старые номера 0.43.5 внутри ТЗ относятся к этапу 0.45.0.

## Интеграция и ограничения

- Общая подготовка: `pa26_executor` и `pa26_workspace`; общий последний барьер — `env.send`. Настройки обязательной RP — существующее русское поле ручной `/setmark`, независимо от включения вопроса о ручной команде. Не создавать второй RP-реестр.
- CEF: `pa26_chat_bridge`, оба PA JS, оригинальные main.js/DLL и замороженная платформа обновления не меняются. Известный clean-install отказ при новом SHA — безопасный native-only режим 0.44; общее исправление без доказанного контракта недопустимо.
- Карта: существующие `pa26_map_adapter` и `pa26_map_grid`, transient проекция остаётся в штатном callback. Никаких собственных обработчиков кликов Esc-карты.
- Наблюдение новых сервисов: единственный вызов из `updateGame`; выключенный master — ранний выход без сканирования. Waypoint ≤4 Гц, координаты только полученные сообщения ≤2048 байт с ограниченным TTL/cache, cruiser только при opt-in и проверенном backend, заметки кэшируются по revision. Отрисовка ограничена 256 сегментами/одной заметкой/четырьмя индикаторами. Новых обработчиков ввода CEF нет.
- Дорожный FFI/управление машиной не включать без независимой проверки ABI/ключей: тестовая модель не доказывает безопасность GTA. Реальные native вызовы, Esc-map маршрут и игровая плавность — NOT RUN до отдельной приёмки.
