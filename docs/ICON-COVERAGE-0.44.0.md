# Иконки 0.44.0

Использован оригинальный **Font Awesome Free 6.7.2 Solid**, 40 закреплённых глифов. Pro-глифов и эмодзи нет. [Официальный релиз](https://github.com/FortAwesome/Font-Awesome/releases/tag/6.7.2). Полные байты, названия и codepoint находятся в `moonloader/resource/pa26/fonts/manifest.json`; оригинальная лицензия — в соседнем `LICENSE.txt`. Для шрифта действует SIL OFL 1.1, для иконок CC BY 4.0, для кода MIT согласно полной лицензии пакета.

SHA-256 оригинального TTF: `af19d135d3a935b3ebfbd80320716ffe1202052c5f68dc2c5f1abc57005ac605`. SHA-256 оригинальной лицензии: `9b914eae88817d63b576eab5aafde7068c7a1abae125d7cdfb034f1da43a9afc`.

| Область | Решение |
|---|---|
| F9 | Семантические иконки восьми разделов, основных переходов и заголовков |
| F4 | Машина/цель, остановка и погоня, критические действия и семейства докладов |
| Патруль | Смена, экипаж, управление сеансом и настройки |
| Настройки | Значимые разделы и действия; простые поля не перегружены значками |
| ВАЖНОЕ | Десять тематических иконок, предупреждения происхождения и реальные переходы; без значка у каждой статьи |
| Уведомления / подтверждения | Информация, вопрос, предупреждение; текст и ДА/НЕТ остаются основными носителями смысла |
| Прочие инструменты | Общий слой кнопок/заголовков для биндов, процедур, заметок, справки и служебных инструментов |
| Радиальное меню | Сохранено устойчивое текстовое колесо: в этом этапе глифы в геометрию/выбор сектора не добавлялись |

Иконки рисуются в отдельном от текста отступе. Стабильная подпись-ID и callback остаются прежними. Узкие элементы сначала теряют декоративный глиф; текст продолжает переноситься. Простые переключатели/числовые поля и часть коротких кнопок остаются текстовыми — это ограничение визуального шума, не отсутствие функции. Поиск, RP и сохранённые бинды не получают PUA-символы.

Загрузка выполняется один раз при инициализации atlas. Реальный x86 mimgui подтверждает MergeMode/DstFont, явный срок жизни буфера, совместимость с кириллицей и наличие всех 40 глифов через `FindGlyphNoFallback`. Нет чтения TTF, построения atlas или загрузок из сети при нажатии кнопок/наборе текста. Отсутствие шрифта оставляет текстовый интерфейс; пользователь также может отключить иконки.

Старый программный worker не принимает новый TTF как отдельный payload. Поэтому update содержит тот же оригинальный шрифт, **полную лицензию и полный manifest** в `pa26_icon_font.lua`. Runtime загружает его из памяти; установочный архив дополнительно содержит обычные файлы. `tools/verify-package.py` декодирует контейнер и требует полного побайтного совпадения. Обновлятор и его разрешённые типы не переписаны.

Проверки: `test_icons_native32.lua` — 513 проверок, 56 кадров, семь размеров, два масштаба и два состояния иконок; `test_ux0440_native32.lua` — десять представлений, 560 кадров. Это CPU-проверки установленной библиотеки, не запуск GTA и не проверка Windows 7 VM.
