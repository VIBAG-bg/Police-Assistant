# Адаптивные окна и восстановление — 0.44.0

Основа новых установок — выбранные владельцем координаты на экране 2560×1440, прочитанные 01.11.2026. Сохранены только сведения об оформлении: F9 2251×1339 в точке 16,31; HUD 2278,409, масштаб 1. Профиль, контакты, заметки и RP-тексты из игры не копировались. По уточнению владельца от 02.11 в публичном наборе `presets/pa-settings.json` исправлена только геометрия окон/HUD; авторские RP и бинды сохранены.

Размеры по умолчанию и минимальный размер при ручном изменении разделены. Новые F4 и окна процедур шире прежних; F4 получает ориентир 1440×1180, а на меньших экранах — пропорциональный размер с нижним пределом, достаточным для читаемых колонок. Ограничения экрана имеют приоритет. При недостатке места содержимое прокручивается; кнопки не обрезаются ради отсутствия полосы прокрутки.

Корректная сохранённая геометрия имеет приоритет, включая вручную выбранное узкое F4. При смене разрешения размеры и положение пересчитываются относительно записанного разрешения. При восстановлении UI после ошибки отбрасывается незавершённое перетаскивание, затем применяется последняя корректная геометрия. Пустые/повреждённые размеры получают согласованный адаптивный вариант. Раньше восстановление сбрасывало все окна, в том числе F4 до 680 px.

В «Настройки → Окна» доступны сохранение расположения, альтернативный процент размера главного окна и явный сброс всех окон к авторскому расположению. Сам ползунок не перетирает настроенный размер: применяется соответствующей кнопкой. Декоративный баннер использует оставшуюся высоту, поэтому не вытесняет действия с главной страницы. Контакты продублированы слева только при достаточной высоте для всех восьми пунктов; нижняя строка контактов остаётся доступной всегда.

HUD сохраняет исходное разрешение и использует относительную привязку. Правая граница авторского расположения остаётся у правого края. Верхняя координата не зависит от количества временных строк патруля. Масштаб адаптируется с нижним пределом читаемости и верхним пределом 2. Внешний вид HUD можно менять и сбрасывать через прежний интерфейс; добавлен переключатель адаптации к разрешению.

Старые INI без исходного разрешения сначала сохраняют свои координаты на фактическом экране пользователя. Это однократная миграция в памяти; запись выполняется прежним отложенным сохранением с резервной копией. Авторское разрешение 2K к чужим старым координатам не приписывается. Новая установка использует отдельное очищенное описание геометрии из программного манифеста. Существующие файлы установщик сохраняет по прежним правилам; программный update не содержит пользовательских JSON или INI.

## Ручная проверка в GTA / Exsellent

1. Сохранить копию пользовательских файлов и запустить тестовый комплект отдельно. Проверить 1366×768, 1920×1080, 2560×1440 и 1152×864. Открыть F9: все восемь разделов на стандартном масштабе доступны без прокрутки навигации.
2. Открыть F4, розыск, штраф, пеленгацию и окно оснований. Проверить читаемые поля, действия, подтверждения и доступность нижних элементов; длинный реальный материал может прокручиваться.
3. Изменить вручную размер/положение F9, F4 и HUD, закрыть PA, перезайти. Размеры должны сохраниться. Повторить после смены разрешения и возвращения обратно.
4. С незаписанным черновиком открыть восстановление `/pa26repair`. Проверить сохранность черновика/геометрии, отсутствие самопроизвольных отправок и повторов предыдущих действий. Повторить после контролируемой ошибки UI на тестовой копии.
5. В отдельной тестовой копии повредить только геометрию и убедиться, что резервная копия/восстановление не теряют бинды, профиль и RP. Не редактировать рабочие файлы без копии.
6. Проверить явный сброс окон, применение процента и сброс HUD; затем изменить их снова. Проверить состояние переключателя адаптации после перезахода.
7. Проверить движение/Alt/правое перетаскивание, клики по элементам HUD и оружие при открытом CEF-чате. Не менее 15 минут проверить набор, выделение и отправку, включая повторное соединение после перезапуска PA.

Автоматическая и нативная CPU-отрисовка проверяют геометрию и структуру. Они не доказывают поведение внутри GTA, масштабирование драйвера/DPI, плавность ввода в игровом CEF или совместимость с реальной Windows 7 VM.


## Приёмка новых докладов и native-only установки

1. В тестовой сессии с включённой службой и рацией передать реальную `/cuff ID`: должен появиться один готовый доклад, а не форма события. N ничего не передаёт. Повторить команду, проверить результат на сервере и нажать Y: один доклад в сохранённый канал, без повторной `/cuff`.
2. Повторить для `/arrest ID`: отдельный текст о КПЗ. Команда без корректного ID и отмена до её отправки тост не создают. Демо не создаёт реальный автоматический доклад.
3. Проверить ручные кнопки «Задержан · доклад» / «КПЗ · доклад» в F4 без таймера патруля. Изменить шаблон/канал/время и выключатели в «04. Патруль → События → Настройки», перезайти и сверить предпросмотр с отправкой.
4. Проверить Y/N при вводе, Alt, срочном SOS, смене ID, выходе из сеанса и отмене до первой строки. Доклад не должен сам отправляться после закрытия чата или перезахода.
5. На копии клиента с неизвестным SHA HUD проверить обычную установку: нативные файлы PA ставятся, исходный `main.js`, HTML, JS и DLL сохраняются; в PA видна причина отключённой CEF-интеграции. `-RequireCef` должен остановиться до записи. Не менять SHA в контракте для обхода проверки.
6. Обычное обновление программы сохраняет свои размеры. Явное применение авторских настроек после предупреждения использует новые адаптивные размеры F4/F9; резервная копия прежних значений доступна.
