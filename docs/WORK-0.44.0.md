## Обнаруженные ограничения

Старый worker разрешает только перечисленные `resource/pa26/*.json`, PNG и свои Lua-модули. Он не принимает новые TTF/TXT. Менять замороженную платформу или ломать переход старым обновлятором нельзя. Проверяется совместимый вариант: оригинальный локальный TTF в установочном комплекте + побайтно проверяемый Lua-контейнер того же шрифта и лицензии в программном update; однократная загрузка из памяти при инициализации, без записи/скачивания во время игры. Способ проверен на реальном x86 mimgui и в переходах старого worker; описан в RELEASE и ICON-COVERAGE.

Фактическая привязка mimgui содержит `ImFontConfig.MergeMode`, `FontDataOwnedByAtlas`, `AddFontFromMemoryTTF`, `FindGlyphNoFallback` и `AddTextFontPtr`; это проверено нативным CPU smoke-тестом, но не является игровым тестом GTA.

## Финальные уточнения

Реализованы адаптивные авторские размеры и сохранение корректной геометрии при восстановлении. Главная приведена к образцу владельца: баннер → личное дело → действия. Два синтетических превью проходят проверку всех восьми разделов и нулевой прокрутки на 1920×1080/2560×1440. Публичный набор обновлён только по геометрии; свежий установщик и явное применение авторских настроек используют согласованную адаптивную раскладку.

Полный финальный LuaJIT-прогон: 196 группы, 12 801 327 проверок, 361 Lua-файла синтаксиса. Текущие пользовательские данные сверены в памяти с 0.43.5: 3164 прежних значений сохранены. Замеры и границы — в PERFORMANCE; конечные нормативные вопросы — в KNOWLEDGE-AUDIT.

Оставлено владельцу: ручная GTA/Exsellent приёмка, 15 минут CEF PA ВКЛ/ВЫКЛ, текущий полный клиент лаунчера, реальная Windows 7 VM и ручная нормативная сверка. Владелец разрешил публикацию после проверок; установка в рабочую GTA остаётся отдельным действием.

Отдельный повтор legacy MAX_PATH выполнен с коротким временным корнем внутри разрешённой рабочей папки: длинный TEMP самого инструмента превышал лимит ещё при создании фикстуры. Политика legacy/.NET остаётся включённой; системный реестр не меняется.

Итоговый шлюз `tools/verify-release0440.py` завершился успешно. Комплект проходит финальную подготовку к разрешённой публикации. Статус публикации проверять по GitHub/PUBLICATION.json; рабочая GTA не изменялась.
