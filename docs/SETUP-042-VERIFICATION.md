Проверки выполняются на отдельных копиях каталогов, без запуска GTA, серверных отправок и записи в настоящую игру.

Полная регрессия Lua выполнена на тех же Lua-исходниках. После неё исправлен узкий обработчик повреждённой версии в PowerShell-представлении статуса; он проверен отдельным набором окна. Снимки в инструкции получены из настоящих WinForms-контролов с вымышленным путём игры и не являются проверкой сервера.

Windows 7 SP1 требует PowerShell 5.1 и .NET 4.5.2+. Ранний запускатель оставлен на синтаксисе PowerShell 2 и проверяется отдельно; матрица старой среды воспроизводится тестовыми значениями. **Настоящая виртуальная машина Windows 7 в этой проверке не использовалась.** Совместимость самой GTA-сборки и ASI остаётся отдельной приёмкой.

Для первого перехода старый помощник ещё не умеет открывать новое автоматическое окно. Отдельный пункт «Показать обновление PA.cmd» подключается к уже начатому заданию и не записывает файлы игры. Со следующего обновления окно работает автоматически, если его переключатель включён.

Повторение проверок: [разработка](DEVELOPMENT.md). Результаты текущего выпуска и публикации: [release-validation.json](release-validation.json).
