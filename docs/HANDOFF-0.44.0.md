# Передача локального кандидата 0.44.0

Реализация и локальная автоматическая проверка завершены. Архивы находятся в `dist/`: установочный комплект, отдельный программный update и исходники/контекст. SHA-256 и итоговый статус — в `dist/SHA256SUMS.txt` и `dist/LOCAL-RELEASE-0.44.0.json`. Последний шлюз: `python tools/verify-release0440.py`.

База — поддерживаемая 0.43.5, HEAD `b6e58d623b889cb3054a7ecde52767090a41e403`. Версия программы/манифеста/проверок — 0.44.0. Авторские RP/бинды сохранены; в публичном наборе изменена только разрешённая геометрия; текущие локальные пользовательские файлы проверены в памяти без записи и экспорта значений. Установленная GTA, исходный `main.js` и DLL не изменялись. Владелец разрешил push и публикацию 0.44.0 после проверок. Установка в рабочую GTA не разрешалась. Фактический статус публикации подтверждается GitHub и PUBLICATION.json.

Последнее уточнение главной реализовано: баннер сверху → компактное личное дело → быстрые действия. Синтетические F9-превью 1920×1080 и 2560×1440 показывают всю страницу и все восемь разделов без прокрутки. Эти изображения не являются игровым свидетельством. Геометрия новых установок/сброса опирается на очищенную авторскую раскладку 2560×1440; корректные личные размеры приоритетны.

Проверки: 196 LuaJIT-групп, 12 801 327 проверок, синтаксис 361 Lua-файлов; native x86 окна/иконки/формы, CEF-синтетика, свежая/повторная установка, откат и переход старого worker 0.43.2/0.43.5 в native/launcher фикстурах. Legacy MAX_PATH: установщик 35 проверок, worker 224; короткий TEMP задавался только тестовому процессу в рабочей папке, реестр не менялся. Полные привязанные к исходникам свидетельства — `docs/qa/0.44.0/`.

Оставшаяся приёмка владельцем: реальная GTA/Exsellent, 15 минут чата PA ВКЛ/ВЫКЛ с frame-time/input-to-paint, текущий полный клиент лаунчера, ответы серверных команд, DPI и Windows 7 VM. Четыре нормативных неизвестных, конфликт рейдов и ручные сверки источников перечислены в KNOWLEDGE-AUDIT. Это не задачи, объявленные успешными по стенду.

Новые функции GPS/навигации/помощи водителю сюда не добавлять: это отдельный этап 0.45.0. При следующем продолжении сначала прочитать RELEASE, UX-TEST-MATRIX, GEOMETRY и PERFORMANCE; не заменять личные бинды или пресеты владельца.


## Финальное дополнение 02.11.2026

Готовые доклады `/cuff ID` и `/arrest ID` находятся в `pa26_custody_*`; настройки в `patrol_events.command_reports`, GUI «Патруль → События → Настройки». Триггер — реальная передача команды, перед радиодокладом обязательна Y/N. Контракт CEF проверяет новый `pa26_cef_compat` один раз вне моста. Неизвестный HUD означает native-only; полный инсталлятор также оставляет CEF нетронутым. Программный ZIP не содержит CEF. Публичная геометрия авторского набора исправлена; RP/бинды не менялись.

Восемь новых upstream-коммитов документации и галерея сохранены; базовый код 0.43.5 не заменён более старым снимком. После сборки обязательны collect-qa0440, verify-release0440, проверка состава git diff, fast-forward push и верификация всех активов GitHub до объявления выпуска готовым.
