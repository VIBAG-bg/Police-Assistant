# Проверка выпуска 0.40.3

Опубликован [релиз 0.40.3](https://github.com/VIBAG-bg/Police-Assistant/releases/tag/v0.40.3), исходный коммит `5e28cea99bb6b6cb2b18552728182e340cc4bf61`.

## Что проверено

- Оба прогона GitHub Actions для [main](https://github.com/VIBAG-bg/Police-Assistant/actions/runs/40500275511) и [тега](https://github.com/VIBAG-bg/Police-Assistant/actions/runs/40500429599) успешны. 149 групп Lua; основной прогон — 8 816 274 проверки, включая 358 проверок новых наборов. Также проверены CEF, установщик, обновлятор, окно установки и сборка архивов.
- Две новые галочки установщика проверены настоящим окном Windows; чистая установка, независимый выбор наборов, повторная установка, свои/неполные/повреждённые файлы и откат проверены изолированно. Чистый комплект содержит 83 бинда и две стандартные памятки.
- Прерывание каждой из 60 операций записи с последующим восстановлением оставляет согласованную прежнюю или новую пару JSON/INI. НЕТ не пишет файлы. Внешние правки и смена источника блокируют устаревший импорт.
- 32-битный помощник скачал оба JSON из опубликованного релиза. Байты, SHA-256, структура и число биндов совпали. Проверены Unicode IO, настоящий SHA-256 и эксклюзивная блокировка.
- Помощники 0.40.1 и 0.40.2 увидели публичный релиз и проверили его архив. Переход 0.40.2 → 0.40.3 выполнен в отдельных установках обычного SA:MP и лаунчера: 95 файлов программы, личные данные и CEF сохранены.
- Обновлятор Lua, платформенный загрузчик и PowerShell worker побайтно совпадают с 0.40.2. Авторские наборы загружаются независимо, по отдельной кнопке и подтверждению.
