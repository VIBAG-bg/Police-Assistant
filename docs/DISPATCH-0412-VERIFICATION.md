# Контроль выпуска 0.41.2

Результат итогового прогона и контрольные суммы записываются в [release-validation.json](release-validation.json). Автопроверки используют изолированные файлы и имитацию игровой сцены; реальные DLL ImGui проверяются отдельным процессом x86 без запуска GTA.

| Требование | Проверка |
| :--- | :--- |
| Игрок за рулём | Подключение, NPC, существование персонажа и обратное сопоставление ID; пустые/пассажирские машины исключены; граница 0–60 м. |
| Выход водителя | Уже выбранная машина сохраняется; возврат в салон/пешая погоня; сохранение захваченной личности, смена поколения ID, ручная цель и смена машины. |
| Миграция 2 | Меняются только два указанных переключателя; личные диапазоны, шаблоны и выключения после миграции сохраняются. |
| Пять вызовов | Пешком и в машине, женский род, правильный порядок RP → рация, реальные байты CP1251 и переносы, отсутствие `/su`, `/pt` и GPS-команд. |
| Состав на ограбление | Оценки 1/2/3, настраиваемый порог, подсказка, изменение состава до ДА и между строками. |
| Требование на АЗС | Каналы `/m` и `/s`, выключатель мегафона, редактирование, контекст пункта 8.2, отсутствие побочного изменения счётчика. |
| Настройки | Валидатор, неизвестные переменные, запрет серверных команд в RP, предпросмотр и сохранение новых полей через GUI. |
| Две страницы | Все шесть кнопок в F4 «Трафик и погоня» / «Патруль»; НЕТ без отправки, ДА через общий исполнитель. |
| Экран | Настоящий ImGui x86, новые RP-поля и длинное подтверждение на семи разрешениях 640×480–2560×1440. |
| Обновление | Старые помощники, обычная/официальная CEF-установка, резервирование и откат с ошибкой в середине/конце записи. |
| Окна установщика | Ошибочная папка → понятное объяснение → правильная папка → установка → проверенный SUCCESS. Настоящие TextChanged/Click/Tick в Windows PowerShell 5.1; наблюдатель обновления также проходит цикл backup → success. |

Открытая игровая приёмка: реальное меню сервера, фактическая доступность `/m` пешком и отправка на живом сервере. Это не заявляется проверенным автоматическими тестами. Локальные игровые файлы этим выпуском не устанавливаются.

Сверены только упомянутые пункты общего регламента; полного повторного обхода форума не было. Существующие база, авторские файлы, CEF и замороженный загрузчик защищены сравнением с предыдущей версией. Запуск в Windows 7 VM не проверялся; тестируются условия совместимости и реальный Windows PowerShell 5.1 на текущей системе.
