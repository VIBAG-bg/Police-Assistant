# Бинды, заметки и личные данные

[← Руководство](GUIDE.md)

## Создать бинд

1. F9 → **Библиотека биндов** → **«+ Новый сценарий ( Добавить бинд )»**.
2. Введи название, категорию и условия. Если нужен человек, укажи это явно.
3. Выбери режим полного текста или отдельных шагов. Добавь реплики, переменные и необходимые паузы.
4. Назначь сочетание, короткую команду и участие в колесе по желанию. Имя команды вводится **без начального `/`**, например `add` или `pa26_hello` в поддерживаемом формате редактора.
5. Проверь **предпросмотр**, затем нажми закреплённую сверху кнопку **«Сохранить сценарий»**.
6. Сначала выполни в деморежиме, затем проверь в подходящей игровой ситуации.

Пример простого текста:

```text
Здравствуйте. Меня зовут {my_name}.
/me достал служебное удостоверение и раскрыл его перед собеседником.
/do Данные и фотография в удостоверении доступны для ознакомления.
```

Выбирай переменную из каталога редактора: источник и требования показаны рядом. `{id}` и `{select_*}` требуют выбранного человека; свои данные не требуют цели. Длинные поля сохраняют видимую область при выделении; горизонтальная прокрутка позволяет добраться до конца.

## Где лежат файлы

В `MoonLoader/config/`:

| Файл | Содержимое |
|---|---|
| `police_assistant_2026.ini` | Основные параметры запуска и режима |
| `police_assistant_2026_binds.json` | Сохранённые бинды, шаги и способы запуска |
| `police_assistant_2026_notes.json` | Заметки и их избранное |
| `police_assistant_2026_settings.json` | Профиль и настройки функций |
| `police_assistant_2026_library.json` | Старый снимок до переноса на отдельные файлы, если он существовал |

Другие файлы с тем же префиксом содержат отдельные журналы, состояние и личные редакции. Полная резервная копия — весь набор **`police_assistant_2026*`**, а не один файл.

Во время игры PA читает данные в память. Для изменения файлов вручную полностью выйди из GTA, сохрани копию, отредактируй и снова запусти игру. Внешнее изменение работающего документа блокирует сохранение устаревших данных поверх новой версии.

## Обмен биндами

В библиотеке открой меню **«Действия с биндами»**. Оно содержит дублирование, удаление, импорт, экспорт и пояснение файлов обмена.

**Отправитель:** сохрани бинд → «Действия с биндами» → «Экспорт выбранного бинда» или «Экспорт всех биндов» → передай `police_assistant_2026_binds_exchange.json` из папки config.

**Получатель:** помести файл обмена в свою папку config → «Действия с биндами» → «Импорт биндов» → прочитай список и подтверди. Записи добавятся с новыми локальными ID, выключенными, без прежних сочетаний и команд запуска. Прочитай текст, назначь свои способы запуска и включи необходимые записи.

Повторный отдельный импорт создаёт копии. Импорт ничего не отправляет в игру. Профиль и заметки в файл обмена биндов не входят, но собственный текст бинда может содержать личные сведения — проверь его перед передачей.

Для заметок используется **`police_assistant_2026_notes_exchange.json`** и соответствующие кнопки раздела памяток.

## Как сохраняются данные

Проверяются формат, размеры, кодировка, ID и структура. Запись идёт через временную проверенную копию; операции над несколькими документами используют журнал восстановления. Ошибка не считается успешным сохранением. Повреждённый комплект не заменяется молча стандартными значениями.

При обновлении собственные данные не входят в архив замены, сохраняются в отдельную резервную папку и остаются на месте. Автоматический откат программных файлов не затирает более новые личные записи.
