## При установке

Две независимые галочки включены по умолчанию:

- **Установить авторский бинд-лист** — набор сценариев, их команды, клавиши и назначения биндов колесу.
- **Установить авторские настройки** — оформление, категории колеса, размеры и положения окон, HUD и поведение функций.

Чистая установка получает выбранные наборы и **две стандартные памятки PA**. Если галочка выключена, используются обычные стартовые значения соответствующей группы.

Переустановка сохраняет пользовательские данные. Авторские значения автоматически заменяют только целый нетронутый стандартный набор. Даже одно своё изменение защищает соответствующую группу. Изменённый INI, частичный комплект, старый неперенесённый формат или признаки незавершённого сохранения не считаются «пустыми»: помощник сохраняет их. Существующие заметки не заменяются. Профиль и контакты остаются своими даже при замене стандартного оформления.

## Из работающего PA

F9 → **Обновления PA** → выбери одну кнопку:

- **Обновить бинд-лист с GitHub**.
- **Обновить настройки с GitHub**.

PA скачает отдельный JSON из последнего стабильного релиза выбранного репозитория, проверит размер, SHA-256 из GitHub и структуру. До ответа **ДА** ничего не заменяется. **НЕТ** и Esc отменяют применение.

Бинд-лист объединяется с текущим. PA обновляет распознанные неизменённые авторские тексты и добавляет недостающие. Личные бинды и изменённые копии сохраняются. При конфликте действующая команда или клавиша остаётся у текущего бинда. Применение авторских настроек меняет оформление и поведение по набору, сохраняя бинды, профиль, контакты, заметки, напоминания, историю, источник обновлений и режим ДЕМО.

После ДА создаются проверенные копии, затем выбранный набор записывается. Настройки JSON и INI применяются одной восстанавливаемой операцией: после прерывания восстанавливается согласованная прежняя либо новая пара. Внешние изменения блокируют замену. После итогового ОК перезапускается **только скрипт PA**, GTA продолжает работать.

Копии находятся рядом с личными файлами в `MoonLoader/config/` и начинаются с `police_assistant_2026_preset_backup_`. Они не удаляются автоматически. При повреждённой копии или журнале PA останавливает восстановление; сохраняй все связанные файлы.

## Где находятся файлы

В полном ZIP и репозитории есть папка `presets/`. В GitHub Release отдельно приложены **pa-binds.json** и **pa-settings.json**. Их скачивают кнопки PA. Выпуск 0.46.0 также несёт те же авторские наборы в пакете программы для разового объединения после встроенного обновления. Авторский предел второго кольца — 15 действий в пешем и автомобильном режимах.

`pa-binds.json` совместим с обменом биндами PA. `pa-settings.json` содержит оболочку авторских настроек, включая INI: не копируй его напрямую поверх личного `_settings.json`; используй установщик или кнопку в PA. `baseline.json` нужен установщику для распознавания стандартных значений и содержит только стандартные памятки, а не личные заметки автора.

Стандартные отыгровки ручных команд находятся в личном `police_assistant_2026_settings.json`: `data.settings.manual_actions.rules.<команда>.rp`. Они входят в авторский **набор настроек**. Сценарии из редактора находятся в отдельном `police_assistant_2026_binds.json`. Если у ручной команды включено «Сначала брать RP из подходящего включённого бинда», подходящий бинд имеет приоритет; сохранённый стандартный текст при этом не удаляется.
