# PA 0.42.1: принятый объём исправлений

База: опубликованная PA 0.42.0, коммит `3457b9d01b7b982ec6b26a2c638c1dba3539c92e`.
Исходное ТЗ: `gemini-code-1793223413257.md`, SHA-256
`9d80dbd554948460c2ad9ea0da5334456fd78c133ef0baeeee357003366703a9`.

После разбора пользователь разрешил реализацию и уточнил:

- Предел 300 м применяется только к удержанию цели во время погони. В обычной игре прежние условия выбора и взаимодействия сохраняются.
- Переключатели относятся к стандартным RP команд, а не к содержимому личных биндов.
- Доклад одиночного экипажа: «начинаю патруль», «доступен/доступна»; совместного: «начинаем патруль», «доступны».
- Автоматический LINCOLN/ADAM определяется по составу сотрудников в той же машине. Пустое поле юнита не должно блокировать начало патруля.

Остальной принятый объём: ввод без переписывания поля, самостоятельные подтверждения,
жизненный цикл карточки Copilot, Alt+7/8, класс и цвет транспорта, предложения повторов
мегафона, три независимых переключателя RP тайзера, русский GUI и сохранение значений.

Удержание личности не расширяет допустимую дистанцию наручников и других физических
действий. Потеря стрима не считается свежим наблюдением. Повторное предложение
требования не означает автоматическую отправку или разрешение применить силу.

Сохраняется соглашение 0.42.0 об условном номере `SA-%03d` и автомобильном пути
розыска. Обычный `/su ID` сохраняет полный помощник. Нормативные источники не меняются.

Загрузчик, работник обновления и установочные помощники не изменяются. В публичных
настройках первой установки изменён только стандартный флажок демо после восстановления;
авторские бинды и остальные значения сохранены. Игра пользователя не перезаписывается.
29.10.2026 пользователь отдельно разрешил публикацию 0.42.1 на GitHub сразу после проверок.

Обычный вход в больницу и запрос спавна отдельно недостаточны.
