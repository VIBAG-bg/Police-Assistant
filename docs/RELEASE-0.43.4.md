# Police Assistant 0.43.4 — исправление окна патруля

Исправлено падение **F9 → Напарники → Патруль**. Если личному шаблону нужен неизвестный курс, PA теперь показывает понятное предупреждение. Окно остаётся доступным, остальные предпросмотры продолжают работать, а личный текст сохраняется.

- Исправлена такая же потеря ошибки в SOS, Shots fired, CODE 0 и других докладах. Невалидный доклад не отправляется.
- Добавлены проверки отсутствующих и неверных данных места, формы доклада и экипажа. Неизвестный район, отсутствующий квадрат и выключенная сетка поддерживаются.
- Защищён вывод необязательной истории патруля. Штатное восстановление интерфейса и `/pa26repair` сохранены.
- Сохраняются личные шаблоны, настройки, бинды, заметки, история и профили. Значения по умолчанию и формат данных не менялись.

CEF-адаптер и мост сохранены побайтно. В главном скрипте и защитном загрузчике обновлены только номера версии. Новых опросов, таймеров, FFI-хуков и файловых операций в отрисовке не добавлено. Платформа обновления и установщик сохраняют прежнюю логику.

Проверки: **188 групп / 11,471,193 проверок**, 1260 нативных проверок x86 на семи разрешениях и 560 проверок JavaScript. Переход старым обновлятором с 0.43.3 прошёл все 318 проверок для обычной сборки и лаунчера. Точные результаты и SHA записаны в [отчёте проверки](https://github.com/VIBAG-bg/Police-Assistant/blob/v0.43.4/docs/validation-0.43.4.json).

В настоящей GTA эта версия ещё не проверена. [Короткий чек-лист](https://github.com/VIBAG-bg/Police-Assistant/blob/v0.43.4/docs/F9-REPORT-VALIDATION-CHECKLIST.md) позволяет проверить исправление без сброса настроек. [Подробный разбор причины](https://github.com/VIBAG-bg/Police-Assistant/blob/v0.43.4/docs/F9-REPORT-VALIDATION-FIX.md).

Обновление доступно через раздел обновления PA. Дождитесь завершения установки после выхода из GTA. Локальная игра разработчика этой публикацией не обновляется.
