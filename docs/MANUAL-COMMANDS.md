# Ручные команды и своё круговое меню

[← Руководство](GUIDE.md)

## Ввести `/cuff ID` вручную

PA удерживает исходную команду и открывает **«Отыграть действие перед командой?»** с RP-предпросмотром.

- **ДА** — выполнить показанные RP-строки, затем передать исходную команду один раз.
- **НЕТ** — передать только исходную команду.
- **Esc** — отменить и RP, и команду.

В деморежиме оба варианта показывают результат без отправок. При отключении игрока, повторном использовании его ID, смене подключения, потере фокуса или изменении настроек подготовка отменяется. Отправка самим PA повторно не вызывает это окно. Уже выполненные RP-строки не повторяются после отмены; серверный результат нельзя установить по самому факту передачи команды.

Сначала PA ищет включённый бинд с нужной серверной командой в конце. Для подготовки подходят только RP-строки и паузы до неё; другие серверные команды или дополнительные действия из такого бинда не выполняются. Если бинд не подходит или его контекст недоступен, используется настраиваемый резервный RP-шаблон. ID для персонального RP берётся из введённой команды, а не из случайно выбранного другого игрока. Параметры серверного хвоста не рассчитываются заново и не делятся на сообщения.

Настройки: **F9 → Инструменты → Команды сервера · сверка**. Внизу доступны общий переключатель, выбор команды, её включение, приоритет бинда, многострочный резервный RP и пример результата. Новое имя добавляется без `/` и параметров. Все значения сохраняются в пользовательских настройках. Доступно до 64 имён.

Переменные RP: `{param1}`…`{param8}`, `{params}`, обычные переменные профиля/биндов и `{gender:мужской|женский}`. Например, в `/cuff 37` первый аргумент — `{param1}`. `{select_id}` и `{select_name}` требуют доступного игрока из команды. Подстановка имени не устанавливает IC-личность.

По умолчанию настроены действия из имеющейся серверной справки. Для неизвестной команды добавьте имя и свой RP. `/su` и `/wanted` используют существующий помощник розыска. Текстовые `/me`, `/do`, `/try`, `/todo`, чат, рация и мегафон сохраняют свой порядок работы. Подтверждение RP не заменяет основания действия, известный IC-телефон или требования регламента.

## Короткая команда бинда

`/название` и `/pa26_название` направляются в локальный обработчик PA. Для CEF больше не требуется префикс `pa26`. Запасной обработчик принимает локальный псевдоним и при запаздывании обновления списка CEF. Отправки серверу самого псевдонима нет.

Переименование, отключение или удаление бинда обновляет список доступных команд. Занятое имя показывается отдельным предупреждением. Не назначайте одно имя двум биндам.

## Перенести CODE 0 или розыск

**F9 → Настройки → Доступ → Радиальное меню → Куда поместить встроенные действия**. Выберите секцию для SOS, Shots fired, CODE 0, мегафона, каждого действия патруля и каждой формы процедуры. В списках используются ваши названия секций. «Стандартная секция» возвращает обычное размещение.

В профилях с 4/6 секциями скрытые категории объединяются так же, как категории биндов. Назначение сохраняется; при возврате к 8 секциям действие возвращается в свою полную категорию. Наличие CODE 0 в другой секции не отменяет его условие здоровья. Перенесённое действие доступно и в поиске соответствующей секции.

## Показать 10 действий во втором кольце

В том же разделе включите **«Своё число действий второго кольца»** и задайте **10** в поле **«Действий перед кнопкой поиска»**. При 10 или меньшем числе действий показываются все; при большем — первые 10 и дополнительный сектор «Ещё и поиск». Допустимо 1–16. Более крупное кольцо занимает большую дугу, длинные названия сокращаются по доступному месту. «Авто» возвращает прежнюю компоновку.
