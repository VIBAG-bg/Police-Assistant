# Police Assistant 0.45.1 — локальный кандидат

Обновлены 83 авторских сценария RP и 34 правила ручных команд по [утверждённому ТЗ](specs/PA-0.45.1-AUTHORITATIVE.md). Пакет подготовлен для проверки; установка в GTA и публикация ещё не выполнялись.

## Что изменилось

- Пешее колесо: восемь разделов в заданном порядке. «Свои бинды» остаётся отдельным личным разделом. Следственные и экспертные действия доступны в F9; дополнительные действия задержания — в «Ещё».
- Колесо в машине: шесть разделов со своими названиями и порядком. Убраны неподходящие пешие действия, добавлены существующие действия Copilot, патруля, ориентировок и навигации.
- Представление при 10-55, первое требование мегафона и 10-66 учитывают класс машины из существующего Copilot. При неизвестном типе сначала показываются оба точных предпросмотра. Для мотоцикла не отыгрываются двери, салон, окно и багажник.
- Этапы 10-66 подтверждаются отдельно. ДА передаёт текущий этап, НЕТ / Esc останавливает оставшееся. Задержки и время ожидания решения доступны в настройках.
- Мужские и женские формы, `/me`, `/do`, `/todo`, задержки и ограничения длины проходят через существующий исполнитель PA. Команда, колесо, F4/F9 и клавиша используют общую подготовку.
- Уточнены радиокоды 10-6 / 10-8. Обычная погоня не объявляется CODE 1; общее требование остановиться не содержит безусловной угрозы огнестрельным оружием.
- Ник, SA:MP ID и клиентские сведения не считаются доказательством IC-личности или результатом базы. Для соответствующих реплик нужны прежние сведения о предъявленном паспорте либо отдельное решение офицера.

## `/setmark` и технические уточнения

Утверждённая RP `/setmark` сохранена дословно в A40 и ручной команде. Общая защита подготовки и исключения повторов остаётся прежней. Новых документов, оснований или разрешающих окон для `/setmark` нет.

В старом публичном бинд-листе A40 ещё содержал устаревшую общую фразу. Новый авторский A40 приведён к уже утверждённой ручной RP из 0.45.0 и к текущему ТЗ; сама утверждённая RP не переписана. Личные отредактированные копии импорт не заменяет.

Есть [пять необходимых уточнений текста](qa/0.45.1/RP-DEVIATIONS.md): в четырёх местах SA:MP ID заменён отдельным полем номера значка; одно действие `/todo`, превышающее 60 символов, сохранено целиком отдельной `/me` с последующей речью. Номер значка задаётся в профиле, автоматически из ID он не получается. Остальные утверждённые тексты сохраняются точно.

A53 показан в двух разделах автомобильного колеса: основной — «Погоня и 10-66», дополнительный — SOS. Это выполняет обе явные раскладки раздела 3 ТЗ; сводная таблица раздела 4 называет только основное место. Второе место использует тот же бинд, без копирования и двойной отправки.

## Сохранность данных

Обновление программы не импортирует авторский набор поверх личного. Сохранённые бинды, избранное, клавиши, тексты RP, названия и порядок колеса, профиль и размеры окон остаются пользовательскими.

При добровольной загрузке **бинд-листа** в «Обновления PA» показывается список изменений и запрашивается подтверждение. Обновляются только точно распознанные неизменённые авторские сценарии. Личная редакция сохраняется; новый эталон добавляется отдельной записью. Конфликтующая новая клавиша / команда не назначается. При нехватке места весь импорт отклоняется до записи. Перед применением создаётся проверенная резервная копия.

Загрузка **авторских настроек** — отдельное явное действие с прежним предупреждением о замене настроек. Оно не выполняется автоматически. Бинды, профиль, контакты и заметки не заменяются. Новый публичный формат требует PA 0.45.1; старый PA отклоняет его, вместо потери новых этапов и вариантов RP.

## Сохранённые системы и границы проверки

CEF-адаптер, мост, обработка ввода, граф дорог, GPS и Esc-карта не менялись. `pa26_update_platform.lua` сохранён побайтно с SHA-256 `995b131aa0250b7ea407915ad7d109de71a8e43cec088603bc99cc489e60565f`. Установщик изменён только для включения новых PA-модулей в прежний перечень и контрольные суммы; его контракт CEF и механизмы отката сохранены.

Для перехода с worker 0.44.0 по-прежнему нужен однократный полный установщик, а не кнопка обновления. Существующий проверенный переход с 0.45.0 сохраняется.

Результаты автоматизации и точный состав — [итоговый отчёт](qa/0.45.1/FINAL-REVIEW.md). Это не доказательство работы в игровом клиенте.
