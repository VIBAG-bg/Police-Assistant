# Police Assistant 0.40.3

- Актуальные 83 бинда автора и полные настройки интерфейса/функций включены в установочный архив и приложены к релизу отдельными JSON.
- Две независимые галочки установщика по умолчанию включены: авторский бинд-лист и авторские настройки. Чистая установка получает выбранные значения и две стандартные памятки; свои и частично повреждённые комплекты не перезаписываются.
- На вкладке «Обновления PA» добавлены две отдельные кнопки загрузки наборов. Проверка SHA-256, окно ДА/НЕТ, резервные копии, защита внешних правок и восстановление прерванной записи. После подтверждения перезапускается только PA.
- Настройки колеса, размеры окон, HUD и поведение функций включены. Профиль, контакты, личные заметки, история и личная база автора исключены. При импорте свои профиль, контакты, заметки, журнал и ДЕМО сохраняются.
- Сам обновлятор программы, его загрузчик и PowerShell worker не изменены. Кнопка обновления PA по-прежнему обновляет программу; авторские наборы применяются отдельно.

[Правила установки и применения](https://github.com/VIBAG-bg/Police-Assistant/blob/main/docs/AUTHOR-PRESETS.md).
