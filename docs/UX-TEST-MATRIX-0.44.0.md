## Разрешения

Общие UI-стенды: 640×480, 800×600, 800×1100, 1024×768, 1366×768, 1920×1080, 2560×1440; обычный и увеличенный масштаб, иконки ВКЛ/ВЫКЛ. Новая геометрия дополнительно проверена при 1152×864 и 3440×1440. Малая площадь или большой пользовательский шрифт могут требовать прокрутки содержимого; кнопки доступны через неё, а не обрезаны.

## Воспроизведение

`python tests/run_tests.py` — полный последовательный прогон. `python tools/run-regression0440.py --jobs 2` — те же изолированные группы в двух независимых процессах, с общей проверкой неизменности исходников. `tests/support/run_game_lua32.ps1` запускается 32-битным PowerShell с выбранным native-тестом. Команды выполняются в копии проекта, не в установленной GTA. Подробные артефакты входят в исходный комплект.
