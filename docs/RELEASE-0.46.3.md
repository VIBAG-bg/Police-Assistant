# Police Assistant 2026 · 0.46.3

## Чат Exsellent Launcher

- Добавлен проверенный профиль HUD от 26 ноября (SHA-256 `5500b67e6fe0…`). После проверки PA восстанавливает подключение адаптера и локальный обмен с чатом.
- PA распознаёт эквивалентную запись таблицы закодированных строк в проверенных HUD. Кавычки, экранирование и разбиение строк могут измениться. Значения и порядок строк, код вне таблицы и разметка чата проходят сверку.
- Если локального совпадения нет, PA один раз запрашивает каталог официального репозитория по HTTPS. Запрос одинаков для всех установок. После сверки с профилем адаптер подтверждает связь при запуске. Для неподтверждённой сборки доступны штатный чат и нативные функции PA.
- В диагностике видно, откуда взят профиль и удалось ли получить официальный каталог. В настройках чата можно отключить сетевой поиск. Настройка применяется при следующем запуске PA.
- Перевод раскладки команд с точкой, перенос длинных сообщений и остальные преобразования выполняются при отправке. Проверка файлов выполняется в фоне при запуске.

## Как обновиться

Открой **F9 → Обновления PA**, скачай обновление и выйди из игры для установки. Для первой установки скачай полный архив и запусти «Установить PA». Если страница HUD была открыта до восстановления адаптера, полностью перезапусти GTA.

## Как добавляется новый профиль

Проверенные профили берутся из `CEF_CONTRACT.json` в основной ветке проекта. Перед публикацией профиля проверяются разметка, отправка и приём сообщений, фокус и подтверждение связи. Для сборки пакетов тот же каталог встраивается в `pa26_cef_contract.lua` скриптом `tools/build-cef-contract0450.py` с обновлением контрольной суммы в манифесте. Установленный PA получает опубликованный профиль при запуске. Если формат сообщений или интерфейс чата изменился, может понадобиться обновление адаптера.

## Проверка в игре

После запуска открой диагностику чата и дождись подтверждения связи. Проверь набор и выделение текста, преобразование команды с точкой, отправку длинной реплики и повторное подключение после перезапуска. Проверка в GTA на сервере для этого релиза ещё не проводилась.
