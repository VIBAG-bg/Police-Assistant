Подготовка Windows к установке PA

Установщик и обновлятор используют Windows PowerShell 5.1 и .NET Framework 4.5.2 или новее. На Windows 10 и 11 они обычно уже установлены. Для Windows 7 нужен Service Pack 1 и отдельная подготовка.

Windows 7 SP1

  1. Проверь выпуск и разрядность Windows в «Панель управления → Система». Если SP1 не установлен, сначала обнови Windows до SP1.
  2. Установи .NET Framework 4.8 Runtime с сайта Microsoft и перезагрузи компьютер, если попросит установщик. Подходит и уже установленная версия 4.5.2–4.7.2.
  3. Скачай Windows Management Framework 5.1 с сайта Microsoft. Для 64-битной Windows 7 нужен Win7AndW2K8R2-KB3191566-x64.zip, для 32-битной — Win7-KB3191566-x86.zip. Распакуй пакет и следуй инструкции Microsoft внутри. Это обновление Windows может запросить права администратора.
  4. Перезагрузи компьютер. Снова запусти «Установить PA.cmd» из полностью распакованного архива PA.

Компоненты Windows не устанавливаются PA скрытно. До прохождения проверки файлы игры не меняются.

Windows 10 / 11

Запусти «Установить PA.cmd», выбери свою GTA/MoonLoader и нажми «Установить». Если проверка сообщает о старом PowerShell, используй штатный Windows PowerShell 5.1, а не консоль старой сторонней сборки Windows.

Нужен ли запуск от администратора?

Обычно нет. Он может понадобиться, если сама игра лежит в защищённой папке и появляется именно «Отказано в доступе». Ошибка You must provide a value expression ... '-' operator указывает на разбор команды: старый PowerShell не понимает современный синтаксис. Повышение прав его не обновляет.

Распакуй PA в обычную папку пользователя. Не запускай установщик изнутри ZIP.

Загрузка не проходит на семёрке

Для GitHub и источников библиотек нужен HTTPS с TLS 1.2 и рабочие корневые сертификаты Windows. Установи доступные обновления Windows и .NET. PA не отключает проверку сертификатов и не подменяет её небезопасной загрузкой. При сетевой ошибке сохраняются прежние файлы.

Матрица требований и ранний отказ проверены автоматическими тестами. Отдельная проверка этой версии в настоящей Windows 7 не выполнялась; совместимость сторонней GTA-сборки, SA:MP и ASI зависит от её компонентов.
