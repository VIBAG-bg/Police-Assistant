# Установка Police Assistant

[← На главную](../README.md) · [Руководство](GUIDE.md)

## Требования

- Windows с Windows PowerShell 5.1, GTA San Andreas и поддерживаемым клиентом SA:MP / Exsellent Launcher.
- Установленный MoonLoader с библиотеками `mimgui` и `encoding`.
- Для CEF-интеграции — совместимый официальный HUD лаунчера. PA проверяет его перед изменением.

Игра, лаунчер, MoonLoader и сторонние библиотеки в архив не входят. Установщик проверяет наличие основных зависимостей; дополнительные требования самого MoonLoader устанавливаются вместе с ним.

## Обычная установка

1. В [последнем Release](https://github.com/VIBAG-bg/Police-Assistant/releases/latest) скачай архив **`Police-Assistant-v<версия>.zip`** (для локального кандидата — `Police-Assistant-v0.40.0.zip`).
2. Полностью выйди из GTA. Не устанавливай поверх работающего скрипта.
3. Распакуй **весь** архив в отдельную папку, сохраняя структуру каталогов.
4. Запусти **`Установить PA.cmd`**. Стандартная папка определяется автоматически: `%LOCALAPPDATA%\Exsellent Launcher\game\MoonLoader`.
5. Дождись сообщения об успешной установке. Если проверка остановилась — прочитай причину, следуй [решению проблем](TROUBLESHOOTING.md), затем повтори.
6. Запусти игру, нажми **F9**, проверь версию и настройки.

Альтернатива из Windows PowerShell, открытого в папке распакованного архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Команда применяет параметр только к этому запуску PowerShell; системная политика не меняется. При ограничении со стороны Windows или организации не обходи запрет — используй разрешённую процедуру установки.

### Что переносится

| Каталог архива | Назначение |
|---|---|
| `moonloader/police_assistant_2026.lua`, `pa26_guard.lua` | Главный скрипт и контроль восстановления |
| `moonloader/lib/pa26_*.lua` | Модули PA |
| `moonloader/resource/pa26/` | Изображения, база знаний, каталог розыска и помощник обновлений |
| `moonloader/config/police_assistant_2026.ini` | Только стартовые значения; существующий файл сохраняется |
| `cef/assets/hud/pa26-chat*.js` | Собственные адаптеры PA для совместимого CEF-чата |

Установщик сверяет SHA-256 исходников с `INSTALL_MANIFEST.json`, резервирует заменяемые файлы и проверяет результат. Он сохраняет существующий INI и не поставляет личные JSON. Оригинальный `main.js` лаунчера не распространяется и не заменяется.

### Нестандартная папка игры

Если у тебя собственная сборка GTA SA:MP со стандартным чатом, PA можно перенести вручную. Автоустановщик рассчитан на стандартную папку Exsellent Launcher.

1. Полностью закрой GTA и сохрани копию всех `moonloader/config/police_assistant_2026*`.
2. Проверь зависимости своей сборки:
   - `moonloader/lib/mimgui/`: комплект mimgui, включая `init.lua`, `imgui.lua`, `cdefs.lua`, `dx9.lua`, `win32.lua`, `cimguidx9.dll`. Старый `imgui` / MoonImGui **не заменяет** mimgui. Используй согласованный комплект для своей версии MoonLoader, не смешивай DLL из разных версий.
   - `moonloader/lib/encoding.lua` и зависимости установленного комплекта encoding.
   - `moonloader/lib/samp/events.lua` и остальные файлы **SAMP.Lua** в `samp/`. Они нужны для ручных команд, распознавания показа паспорта, фильтров чата и событий тайзера. Без событий эти возможности недоступны.
3. Из папки `moonloader/` релизного архива перенеси `police_assistant_2026.lua`, `pa26_guard.lua`, модули `lib/pa26_*.lua` и всю папку `resource/pa26/` в соответствующие места своей сборки.
4. Стартовый `config/police_assistant_2026.ini` копируй **только если своего файла ещё нет**. Существующие INI/JSON, заметки и личную базу не заменяй. Не копируй чужую папку config поверх своей.
5. Папка `cef/` нужна только для совместимого официального CEF-чата Exsellent Launcher. Для обычного чата SA:MP её копировать не надо: Lua-часть использует стандартный игровой ввод. Не изменяй HTML нестандартного лаунчера по догадке.
6. Запусти игру и проверь F9 в деморежиме. Если PA сообщил об отсутствующей библиотеке или функции клиента, исправь установку и перезапусти игру либо используй `/pa26restart`, когда эта команда доступна. Сообщение об ошибке не означает успешную загрузку интерфейса.

## Первый запуск

По умолчанию деморежим включён. В F9 настрой профиль и переменные, посмотри готовую отыгровку, назначь клавиши и только после этого отключай деморежим. Обычный текст, который ты сам отправляешь Enter в игровом чате, остаётся реальной отправкой даже при включённом деморежиме PA.

Имеющиеся бинды и заметки не заменяются стандартным набором. Для старого общего формата PA выполняет проверяемый перенос; исходная библиотека остаётся снимком до миграции.

## Проверить установленную копию

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -VerifyOnly
```

Проверка не устанавливает файлы. Пользовательский INI может отличаться от стандартного — это ожидаемо.
