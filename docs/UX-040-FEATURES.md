# Сохранение F01–F63 в PA 0.40.0

Соответствие прежней матрице 0.39.0. Наличие маршрута проверяется функциональными тестами; это не отметка о ручной приёмке в GTA. Все прежние данные/условия сохраняются. Подтверждения, источники и личные редакции не объединяются с официальным текстом.
