# Переменные PA · аудит 0.6.7-dev · 12 октября 2026

Все 61 переменная каталога имеют путь подстановки. Каждая проверена через настоящий координатор библиотеки и компилятор с подготовленными данными и реальным кодеком CP1251. Это проверка логики; наличие и корректность каждого результата в настоящем клиенте Exsellent ещё требуют игрового прогона.

## Акцент

`{accent}` — сохранённый готовый префикс речи из профиля. В 0.6.4-dev он автоматически применяется к обычной речи, в том числе в биндах; вручную вставлять переменную не нужно. `/me`, `/do` и другие команды не получают этот префикс. Очистка поля с сохранением отключает его для новых сообщений и новых запусков.

## Практические ограничения

- Скорость — значение GTA. Подтверждённого преобразования в км/ч пока нет.
- Транспорт — «Пешком» или GTA model ID. Имя кастомной BMW/Lamborghini на Exsellent автоматически не определяется.
- Номера транспорта, город и полицейский сектор сейчас вводятся вручную. Район `{area}` считывается отдельно; он не заменяет сектор.
- Имя из ника не является проверенными паспортными данными сервера.
- Чужие данные требуют соответствующего видимого доступного игрока. Отсутствующие значения не подменяются догадками.
- Необязательная игровая функция может отсутствовать в клиенте. В таком случае соответствующая переменная не получает значения, и предпросмотр объясняет ошибку.
- Именованные параметры `{param:имя}` также поддерживаются: их создают в редакторе и заполняют при запуске; они не входят в фиксированные 61 строку каталога.

Ручные значения находятся в F9 → «Настройки» → «Профиль и переменные». Сохраните профиль перед подготовкой следующего бинда.

## Как проверить значение без отправки

Создайте короткий бинд с одной переменной. Для реальных значений включите реальный режим и используйте «Предпросмотр текущего текста»; предпросмотр не отправляет строки. Демо может использовать учебные значения, поэтому им нельзя подтвердить настоящее значение ID, оружия или машины. Для чужих данных выберите согласного видимого участника теста; ручные значения сначала заполните в профиле. Все переменные сразу в одну строку не помещать: итог проверяется на 127 байт CP1251.
