# Объём PA 0.42.3

База: опубликованная 0.42.2, коммит `2fe10428415d97f49bbc304ccc405a8e2673091a`.

ТЗ: `gemini-code-1793270913894.md`, SHA-256 `1bb0ec528632e8d8170f61560c6038ac6d16b490e5dcea4d5147f7d0cfb8eb07`. Заголовок правильно указывает 0.42.3 поверх 0.42.2; упоминание 0.42.0 во вступлении устарело.

Пользователь подтвердил проверку и реализацию, затем публикацию сразу после готовности. Дополнительно запросил точную причину ошибки автодоклада в скобках в HUD и подробную запись в журнал PA.

Проверка исходников подтвердила безусловные сообщения в Evidence.cancel / Vehicle.cancel / Forms.reset, недостающую геометрию окна состояния, фильтр розыска без «Все», отсутствие сохранённого порядка/скрытия встроенных секторов и кнопку завершения, которая только закрывала окно.

Уточнения реализации:

- Сохранение порядка колеса и выключение проходят через намерение в основной цикл. Отрисовка не пишет файлы, не читает новые игровые API и не выгружает скрипт.
- Во время редактирования колеса блокируется как клик, так и запуск по отпусканию клавиши. Старые, чужие и несовместимые жесты не применяются.
- Старая форма заменяется до открытия нового `/su`. Очищается только устаревшее состояние процедуры; напоминания и самостоятельные предупреждения не удаляются.
- Геометрия окна сохраняется. Адаптируются содержимое и страницы; для предельно малого окна предусмотрена прокрутка формы. Подтверждения сохраняют отдельные страницы без прокрутки текста.
- Выгрузка допускается только после успешных записей. При ошибке данных нет молчаливого продолжения, черновики требуют решения, незавершённые OOC-обязательства сохраняются.
- Причина зависания у друга на 55% неизвестна: этап и логи не предоставлены. Проверки работника и старых путей выполняются, но отдельная Windows 7 VM не использовалась; неподтверждённое исправление такого зависания не заявляется.
- Замороженный `pa26_update_platform.lua`, работник обновления, CEF и исходный нормативный корпус сохраняют байты 0.42.2. В личную игру эта публикация ничего не устанавливает.
