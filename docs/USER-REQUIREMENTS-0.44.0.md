# Принятые уточнения владельца для 0.44.0

Целевая версия — 0.44.0 поверх актуальной 0.43.5. Ссылки на 0.43.4 в исходном большом ТЗ устарели. Следующие GPS/навигация/помощь водителю относятся к отдельной 0.45.0 и сейчас не реализуются.

Приоритеты: понятный русский интерфейс, доступность всех функций, минимум лишних действий, согласованные Font Awesome и текстовые подписи, F4 для оперативных действий, F9 для навигации и подробной настройки. Сохранение существующих функций, правил отправки, данных, шаблонов, биндов, колёс и личных правок обязательно. Авторские RP/пресеты владелец редактирует отдельно: их не заменять.

Реплики и функциональные параметры настраиваются через русский GUI, с объяснением переменных, предпросмотром и сохранением. Длинные поля не теряют выделение/горизонтальную область. Сохранение бинда закреплено сверху. Результаты кнопок и ошибки показываются отдельным подтверждаемым окном, не временной строкой внизу страницы; успешное фоновое сохранение может быть тихим. Подтверждения ДА/НЕТ растут по тексту или используют страницы, без внутренней прокрутки; ДА зелёное, НЕТ красное. У крестика F9 нет подсказки. Офицеры доступны для взаимодействия наравне с остальными.

Дополнение по геометрии: использовать авторское расположение при 2560×1440 как основу новых установок, явного сброса и восстановления повреждённых размеров. F4 заметно шире старого 680 px. Положение/HUD масштабируются с ограничениями экрана и сохраняют корректные личные размеры пользователя. При ошибке UI не сбрасывать всё к маленьким окнам. Требуются автоматическая геометрия и отдельная игровая приёмка.

Уточнение по главной странице от 01.11.2026: сохранить знакомую иерархию образца — **баннер сверху, личное дело ниже, затем действия**. Всё должно помещаться в просторное стандартное окно. В синтетических превью показать выбранный раздел 01 и все восемь пунктов навигации сразу; использовать демонстрационные данные. Размеры 1920×1080 и 2560×1440. Синтетические изображения не являются доказательством игрового поведения.

Уточнение от 02.11.2026: владелец разрешил выпуск 0.44.0 в GitHub после проверок, безопасный native-only режим при неизвестном CEF и обновление только публичной геометрии пресета. Авторские RP/бинды не менять. Установка и запись в рабочую GTA не разрешались.

Автоматический готовый Y/N-доклад создаётся после передачи реальной `/cuff ID` или `/arrest ID` клиенту. Это принятая владельцем граница подтверждения; PA не называет её доказанным успехом сервера. Пользователь проверяет результат перед Y. Новые тексты и параметры доступны в GUI; ручной маршрут F4 сохранён.

Мост и оба CEF JS не менять. Однократная проверка контракта выполняется вне моста при старте; поклавишной, DOM-обработки и нового протокола не добавлять. Все установочные проверки — в отдельных папках; рабочие пользовательские файлы только читать, их значения не публиковать.
