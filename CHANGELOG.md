# Изменения

## 0.38.0

Первый публичный пакет Police Assistant и официальный канал `VIBAG-bg/Police-Assistant`.

- Страница обновлений над разделами 1–8; проверка и явная загрузка GitHub Release.
- Проверка SHA-256, ограниченный состав архива, ожидание выхода из GTA, свежие копии пользовательских данных и восстановление после прерывания.
- Установочный архив, проверяемый манифест, инструкция, руководство и воспроизводимые тесты.
- Сохранён весь функционал основы 0.38.0-dev: отдельные бинды/заметки, редактор, радиальное меню, удалённый помощник розыска, длинный ручной чат и рация, патруль, HUD с квадратом, транспорт, оружие и база знаний.

Проверка при входе выключена по умолчанию. Скачивание запускается пользователем. Пользовательские тексты и настройки обновление не заменяет.
