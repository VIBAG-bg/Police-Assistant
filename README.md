## Меньше рутины. Больше контроля.

Police Assistant собирает привычные действия сотрудника в одном русском интерфейсе. Настрой отыгровки под себя, выбери нужного игрока, подготовь доклад и проверь его перед отправкой. Бинды и заметки хранятся отдельно — ими удобно обмениваться, а обновление программы их не заменяет.

| Работа | Что помогает PA |
| :--- | :--- |
| **Общение и RP** | Редактор сценариев с шагами, переменными, паузами, сочетаниями и короткими командами. Длинные сообщения продолжаются по словам. |
| **Взаимодействие** | Выбор человека, список рядом, радиальное меню, быстрый доступ и избранное. Офицеры доступны наравне с другими игроками. |
| **Розыск** | Отдельный помощник `/su ID`: личность, паспорт, маска, приметы, причина, RP и окончательное подтверждение. 13 разделов и 31 серверный пункт. |
| **Патруль** | Смена, экипаж, район и квадрат, доклады, происшествия и история работы. SOS / Shots fired / CODE 0 с предпросмотром. |
| **Транспорт и оружие** | Остановка, погоня, требования в мегафон; отыгровки оружия, таймеры и настройки тазера. |
| **Информация** | HUD, памятки, заметки, напарники, поиск по базе знаний и личные карточки. |
| **Сохранность** | Отдельные JSON, проверка внешних изменений, резервные копии, контролируемое восстановление и обновление после выхода из GTA. |

## Новое в 0.43.2

F4 работает с докладами без запуска таймера патруля: предпросмотр, правка данных и ваше подтверждение. Добавлены вложенные доклады по вызовам, редактируемая речь водителю, вопрос об окне по ответу текущего водителя, ориентировки об угоне и быстрый `/pt` рядом. Остановка сохраняется при потере машины из видимости; после общения сначала предлагается завершение, затем при фактическом отъезде — погоня.

## Новое в 0.42.1

Чат сохраняет выделение и положение каретки: акцент и преобразования применяются при отправке. Подтверждения открываются отдельно от меню биндов. Alt+7 выбирает транспорт и предлагает остановку, Alt+8 — погоню. Удержание водителя до 300 м действует только во время активной погони; близкие действия сохраняют свои ограничения.

В стандартных RP команд появился обзор переключателей и три независимые отыгровки тайзера. Пустой юнит патруля определяется автоматически: LINCOLN для одного сотрудника, ADAM для распознанного экипажа в одной машине. Доклады выбирают «начинаю / начинаем» и «доступен / доступны». Патруль сохраняется при ранении и реанимации: 0 HP само по себе не завершает сцену. F6 не останавливает отсчёт доклада, а временные ошибки загрузки не переключают режим. [Как работает защита и что можно настроить](docs/STABILITY-0.42.1.md).

## Начать за пять минут

1. Скачай **`Police-Assistant-v0.43.1.zip`** в [Releases](https://github.com/VIBAG-bg/Police-Assistant/releases/latest). Пункт GitHub **Source code** предназначен для разработчиков.
2. Полностью закрой GTA. Распакуй архив, запусти `Установить PA.cmd` и выбери папку игры. Недостающие библиотеки можно докачать с подтверждением; MoonLoader нужен заранее. [Инструкция](docs/INSTALLATION.md).
3. Открой GTA и нажми **F9**. Первая установка начинает в реальном режиме: действия PA передаются в игру после обычных проверок и подтверждений.
4. В настройках укажи свои данные, удобные клавиши, каналы и тексты. Для проверки без отправки включи **Настройки → 1. Профиль → ДЕМО РЕЖИМ**.

**При первом переходе с 0.40.1 и старее** новое автоматическое окно ещё не запускается старым помощником. Для наблюдения используй «Показать обновление PA.cmd» из полного ZIP после начала загрузки в PA. [Подробнее](docs/UPDATES.md).

Обновления уже направлены на **`VIBAG-bg/Police-Assistant`**: кнопка **«Обновления PA»** расположена слева над разделами 1–8. Проверка при входе по умолчанию выключена; скачивание запускается твоей кнопкой.

## Своё поведение, свои тексты

- Редактируй игровые реплики, интервалы, условия и применимые каналы через GUI. Значения сохраняются между запусками.
- Добавляй сценарий кнопкой **«+ Новый сценарий ( Добавить бинд )»**. В поле имени команды пиши `название`, без `/`: редактор поддерживает обычные и `pa26_`-команды.
- Передавай друзьям файл обмена биндов. Импорт добавляет записи и даёт проверить их перед включением.
- Обычный текст, `/me`, `/do`, `/try`, поддержанные каналы рации и `/todo` используют перенос без разрыва слов. В `/todo` действие после `*` сохраняется в каждой части; максимум действия — 60 символов.

## Совместимость

Windows, GTA San Andreas / SA:MP, MoonLoader, **mimgui**, **encoding/iconv** и **SAMP.Lua**. Игра и MoonLoader устанавливаются заранее; помощник PA может докачать только недостающие библиотеки из закреплённых исходных архивов. CEF-мост рассчитан на проверенный HUD Exsellent Launcher. Для обычного SA:MP используется стандартный чат. [Различия установки](docs/INSTALLATION.md).

PA — пользовательский помощник, не официальный продукт Rockstar Games, SA:MP или Exsellent RP. База правил содержит датированный снимок; действующую редакцию и применимость основания проверяет сотрудник. Передача команды клиенту не означает принятие действия сервером.

**Есть проблема?** [Создай issue](https://github.com/VIBAG-bg/Police-Assistant/issues/new/choose) с версией PA и шагами повторения. Пароли, персональные настройки, журналы и чужие данные прикладывать не нужно.
